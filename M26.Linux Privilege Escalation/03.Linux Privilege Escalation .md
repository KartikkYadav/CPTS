# Linux Privilege Escalation — Services & Internals Enumeration

## 1. Network & Hosts

```bash
ip a
cat /etc/hosts
cat /etc/resolv.conf
ip route
```

**Check:** IP addresses, additional interfaces, internal networks, DNS, and host mappings.

## 2. Users & Login Activity

```bash
lastlog
w
who
cat /etc/passwd
```

**Check:** Currently logged-in users, recent logins, and interesting user accounts.

## 3. Command History

```bash
history
cat ~/.bash_history
find / -type f \( -name '*_hist' -o -name '*_history' \) 2>/dev/null
```

**Check:** Exposed passwords, SSH commands, scripts, and administrative activity.

## 4. Cron Jobs

```bash
ls -la /etc/cron*
cat /etc/crontab
```

**Check:** Scheduled scripts, weak permissions, writable files, and relative paths that could allow privilege escalation.

## 5. Processes & `/proc`

```bash
ps aux
ps aux | grep root
find /proc -name cmdline -exec cat {} \; 2>/dev/null
```

**Check:** Root-owned processes, running scripts, unusual binaries, and process command-line arguments.

## 6. Installed Packages & Sudo

```bash
apt list --installed
sudo -V
```

**Check:** Outdated or vulnerable packages and the installed sudo version.

## 7. Binaries & GTFOBins

```bash
ls -la /bin /usr/bin /usr/sbin
```

Reference: [GTFOBins](https://gtfobins.github.io/)

**Check:** Available binaries that may provide privilege escalation opportunities, especially when combined with `sudo`, SUID permissions, or capabilities.

## 8. System Call Analysis

```bash
strace ping -c 1 127.0.0.1
```

**Purpose:** Trace system calls and observe how a program accesses files, sockets, and other system resources.

## 9. Configuration Files & Scripts

```bash
find / -type f \( -name "*.conf" -o -name "*.config" \) 2>/dev/null
find / -type f -name "*.sh" 2>/dev/null
```

**Check:** Credentials, sensitive paths, scripts, weak permissions, and potentially exploitable configurations.

## 10. Running Services

```bash
ps aux
ps aux | grep root
```

**Check:** Services running as root, unusual processes, and administrator-created scripts or binaries.

## Exam Quick Checklist

* [ ] Network interfaces, routes, DNS, and `/etc/hosts`
* [ ] Current users and login history
* [ ] Bash history and credentials
* [ ] Cron jobs and scheduled scripts
* [ ] Root processes and `/proc`
* [ ] Installed packages and sudo version
* [ ] Interesting binaries — GTFOBins
* [ ] Configuration files and shell scripts
* [ ] Services running as root

**Key takeaway:** Look for outdated software, exposed credentials, root-owned processes, and misconfigured scheduled tasks or scripts that could lead to privilege escalation.
