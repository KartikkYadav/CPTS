# Linux Privilege Escalation — Environment Enumeration

## 1. Initial Enumeration

Identify the current user, privileges, hostname, and network interfaces.

```bash
whoami
id
hostname
ip a
sudo -l
```

**Check for:** sudo privileges, interesting group memberships, and additional network interfaces.

## 2. OS, Kernel & CPU

```bash
cat /etc/os-release    # OS and version
uname -a               # Kernel information
cat /proc/version      # Kernel details
lscpu                  # CPU information
```

**Check for:** outdated OS/kernel versions and potentially applicable public exploits. Kernel exploits may crash the system.

## 3. PATH & Environment Variables

```bash
echo $PATH
env
```

**Check for:** writable directories in `PATH`, misconfigured environment variables, and exposed credentials.

## 4. Shells & Security Defenses

```bash
cat /etc/shells
```

Check for available shells, including `tmux` and `screen`, and outdated shell versions.

**Possible defenses to identify:**

* AppArmor / SELinux
* iptables / UFW
* Fail2ban
* Snort
* Exec Shield

## 5. Storage & Mounted Filesystems

```bash
lsblk
df -h
cat /etc/fstab
mount
```

**Check for:** unmounted drives, accessible backups, sensitive files, and credentials in filesystem configurations.

Other useful command:

```bash
lpstat -t
```

Lists printer and print-job information.

## 6. Network Enumeration

```bash
ip a
ip route
route
netstat -rn
cat /etc/resolv.conf
arp -a
```

**Check for:** internal subnets, additional interfaces, internal DNS servers, and other hosts that may support lateral movement.

## 7. Users & Groups

```bash
cat /etc/passwd
cat /etc/group
getent group sudo
grep "sh$" /etc/passwd
ls -la /home
```

**Check for:**

* Users with login shells
* Users in privileged groups, especially `sudo`
* Service accounts and unusual usernames
* Accessible home directories and sensitive files

`/etc/passwd` fields:

`username:password:UID:GID:info:home:shell`

Common password hash identifiers:

| Prefix      | Algorithm |
| ----------- | --------- |
| `$1$`       | MD5       |
| `$2a$`      | BCrypt    |
| `$5$`       | SHA-256   |
| `$6$`       | SHA-512   |
| `$7$`       | Scrypt    |
| `$argon2i$` | Argon2    |

## 8. Home Directories & Credentials

```bash
ls -la /home
cat ~/.bash_history
find /home -name "id_*" -o -name "authorized_keys"
```

Search for:

* Passwords and reused credentials
* SSH private keys
* Shell history
* Application configuration files
* Sensitive scripts and backups

Check readable `.conf` and `.config` files for exposed credentials.

## 9. Hidden Files & Directories

```bash
find / -type f -name ".*" 2>/dev/null
find / -type d -name ".*" 2>/dev/null
```

**Check for:** hidden notes, configuration files, SSH directories, scripts, and sensitive data.

## 10. Temporary Files

```bash
ls -la /tmp
ls -la /var/tmp
ls -la /dev/shm
```

Look for scripts, credentials, and temporary files belonging to other users.

* `/tmp` — temporary files, commonly cleared at reboot.
* `/var/tmp` — temporary files generally retained longer.
* `/dev/shm` — shared-memory filesystem.

## 11. Automated Enumeration

Run [LinPEAS](https://github.com/carlospolop/PEASS-ng/tree/master/linPEAS) or [LinEnum](https://github.com/rebootuser/LinEnum) when permitted.

**Exam tip:** Understand manual enumeration commands rather than relying entirely on scripts.

## Quick Exam Checklist

* [ ] Current user, groups, and `sudo -l`
* [ ] OS and kernel version
* [ ] PATH and environment variables
* [ ] Running services and security defenses
* [ ] Network interfaces, routes, DNS, and ARP
* [ ] Users, groups, and home directories
* [ ] Mounted and unmounted filesystems
* [ ] Hidden files and temporary directories
* [ ] Credentials, SSH keys, history, and configuration files
* [ ] LinPEAS / LinEnum results

**Goal:** Identify misconfigurations, sensitive information, privileged access, and potential privilege-escalation paths before moving on to permission enumeration.
