# AD ACL Abuse 

## 1. ACL Fundamentals

- **ACL:** Defines who can access an AD object and their permissions.
- **ACE:** Individual permission entry within an ACL.
- **DACL:** Controls which principals are allowed or denied access.
- **SACL:** Defines which access attempts are audited.
- **SID:** Identifies a security principal.
- **Inheritance:** Determines whether permissions apply to child objects.

## 2. Important ACE Permissions

| Permission | Purpose | PowerView Command |
|---|---|---|
| `ForceChangePassword` | Reset a user's password | `Set-DomainUserPassword` |
| `GenericWrite` | Modify writable attributes | `Set-DomainObject` |
| `AddSelf` | Add yourself to a group | `Add-DomainGroupMember` |
| `GenericAll` | Full control over an object | `Set-DomainUserPassword` |
| `WriteOwner` | Change object ownership | `Set-DomainObjectOwner` |
| `WriteDACL` | Modify an object's DACL | `Add-DomainObjectACL` |
| `Add Members` | Add members to a group | `Add-DomainGroupMember` |
| `AllExtendedRights` | Exercise applicable extended rights | Depends on the right |

## 3. Potential Attack Paths

- **Password reset:** Take over an account.
- **Group membership modification:** Gain additional privileges.
- **GenericWrite:** Modify attributes; may enable targeted Kerberoasting.
- **GenericAll:** Gain extensive control over the target object.
- **WriteOwner:** Potentially gain further control over an object.
- **WriteDACL:** Grant additional permissions.
- **LAPS abuse:** May expose local administrator credentials if permissions allow.

## 4. Important Tools

- **BloodHound:** Visualizes AD relationships and attack paths.
- **PowerView:** Enumerates and interacts with AD objects and permissions.
- **ADUC:** Graphically inspects AD permissions.

## 5. Common Attack Scenarios

1. Abuse password-reset permissions.
2. Add a controlled account to a privileged group.
3. Exploit excessive permissions on users, groups, or computers.
4. Chain ACL permissions to escalate privileges or move laterally.

## 6. CPTS Exam Tips

- `ForceChangePassword` = Reset password.
- `GenericWrite` = Modify writable attributes.
- `AddSelf` = Add yourself to a group.
- `GenericAll` = Full control.
- `WriteOwner` = Change ownership.
- `WriteDACL` = Modify permissions.
- **DACL = Access control; SACL = Auditing.**
- Always check **which object** the permission applies to.
- Obtain authorization before making disruptive changes and clean up afterward.

**Key takeaway:** Misconfigured AD ACLs can enable privilege escalation, lateral movement, persistence, and potentially domain compromise.
