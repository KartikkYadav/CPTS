# Enumerating Security Controls

## 1. Overview

After gaining a foothold, enumerate the host's security controls to understand which tools and techniques may be restricted.

Important controls include:
- Microsoft Defender
- AppLocker
- PowerShell Constrained Language Mode
- LAPS

## 2. Microsoft Defender

Defender may detect or block enumeration tools such as PowerView.

**Check Defender status:**
```powershell
Get-MpComputerStatus
```

Important fields:
- `AntivirusEnabled` — Indicates whether antivirus is enabled.
- `RealTimeProtectionEnabled` — Indicates whether real-time protection is enabled.

`True` means the corresponding protection is enabled.

## 3. AppLocker

AppLocker controls which applications, scripts, and executables users can run.

**Enumerate effective policies:**
```powershell
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections
```

Important fields:
- `Name` — Rule name.
- `Action` — `Allow` or `Deny`.
- `PathConditions` — Paths covered by the rule.
- `UserOrGroupSid` — User or group affected.

**Exam tip:** A rule may block a specific executable path without blocking every possible executable location.

## 4. PowerShell Constrained Language Mode

Constrained Language Mode restricts certain PowerShell features, including access to many .NET types and COM objects.

**Check the current language mode:**
```powershell
$ExecutionContext.SessionState.LanguageMode
```

- `FullLanguage` — Most PowerShell language features are available.
- `ConstrainedLanguage` — Advanced features are restricted.

## 5. LAPS — Local Administrator Password Solution

LAPS manages and rotates local administrator passwords to reduce password reuse across Windows computers.

### Find delegated groups
```powershell
Find-LAPSDelegatedGroups
```
Identifies groups delegated permission to read LAPS passwords.

### Find extended rights
```powershell
Find-AdmPwdExtendedRights
```
Identifies users or groups with relevant extended rights on LAPS-enabled computers.

### Enumerate LAPS computers
```powershell
Get-LAPSComputers
```
May display computer names, passwords, and expiration times when the current account has sufficient permissions.

**Exam tip:** Check both which computers use LAPS and which users or groups can read their passwords.

## 6. CPTS Quick Reference

| Command | Purpose |
|---|---|
| `Get-MpComputerStatus` | Check Defender status. |
| `Get-AppLockerPolicy -Effective` | Enumerate effective AppLocker policies. |
| `$ExecutionContext.SessionState.LanguageMode` | Check PowerShell language mode. |
| `Find-LAPSDelegatedGroups` | Identify delegated LAPS groups. |
| `Find-AdmPwdExtendedRights` | Check relevant LAPS extended rights. |
| `Get-LAPSComputers` | Enumerate LAPS-managed computers and accessible password information. |

### Key Takeaways
- **Defender:** Identifies active endpoint protection.
- **AppLocker:** Restricts application execution.
- **Constrained Language Mode:** Limits PowerShell functionality.
- **LAPS:** Rotates local administrator passwords and reduces password reuse.
- **Permissions:** Determine who can retrieve LAPS passwords.
