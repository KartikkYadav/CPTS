# Living Off the Land (LOTL)

## 1. Overview
- **Living Off the Land (LOTL):** Using built-in Windows tools to enumerate systems and Active Directory (AD) without uploading external tools.
- **Benefits:** Useful in restricted environments and may reduce the need to introduce external tools.
- **Note:** Native commands can still be monitored by EDR and Windows logging.

## 2. Basic Host Enumeration

| Command | Purpose |
|---|---|
| `hostname` | Display computer name |
| `[System.Environment]::OSVersion.Version` | Check OS version |
| `systeminfo` | Display system information |
| `wmic qfe get Caption,Description,HotFixID,InstalledOn` | List installed patches |
| `ipconfig /all` | Display network configuration |
| `set` | Display CMD environment variables |
| `echo %USERDOMAIN%` | Show domain name |
| `echo %logonserver%` | Show logon server |

**Exam tip:** `systeminfo` provides a quick overview of the host.

## 3. PowerShell Enumeration

| Command | Purpose |
|---|---|
| `Get-Module` | List available PowerShell modules |
| `Get-ExecutionPolicy -List` | Check execution policies |
| `Get-ChildItem Env: \| ft Key,Value` | Display environment variables |
| `Get-Content $env:APPDATA\Microsoft\Windows\Powershell\PSReadline\ConsoleHost_history.txt` | Read PowerShell command history |
| `Get-Host` | Display PowerShell version information |
| `whoami` | Identify the current security context |

**Important:** PowerShell history may contain sensitive information or references to configuration files.

### PowerShell Logging
- Script Block Logging can record executed PowerShell commands.
- Event ID **4104** is associated with PowerShell script block logging.
- Event ID **400** can indicate a PowerShell engine startup.
- Older PowerShell versions may lack newer logging capabilities.
- Attempted version downgrades can themselves leave detectable evidence.

## 4. Check Security Defenses

### Windows Firewall
```cmd
netsh advfirewall show allprofiles
```
Displays firewall settings for Domain, Private, and Public profiles.

### Windows Defender
```cmd
sc query windefend
```
Checks the Defender service state.

```powershell
Get-MpComputerStatus
```
Displays Defender status, signatures, protection settings, and scan information.

### Logged-in Users
```cmd
qwinsta
```
Lists terminal sessions and their states.

## 5. Network Enumeration

| Command | Purpose |
|---|---|
| `ipconfig /all` | Identify interfaces and IP configuration |
| `arp -a` | List known IP-to-MAC mappings |
| `route print` | Display IPv4/IPv6 routing tables |
| `netsh advfirewall show allprofiles` | Check firewall configuration |

**Exam tip:**
- `arp -a` → Hosts recently learned through ARP.
- `route print` → Known networks, gateways, and routes.
- Routing information can reveal potential network segments for further assessment.

## 6. WMI Enumeration

Windows Management Instrumentation (WMI) supports local and remote system administration and information gathering.

| Command | Purpose |
|---|---|
| `wmic qfe get Caption,Description,HotFixID,InstalledOn` | Installed patches |
| `wmic computersystem get Name,Domain,Manufacturer,Model,Username,Roles /format:List` | System and domain information |
| `wmic process list /format:list` | Running processes |
| `wmic ntdomain list /format:list` | Domain information |
| `wmic useraccount list /format:list` | Local and recognized domain accounts |
| `wmic group list /format:list` | Local groups |
| `wmic sysaccount list /format:list` | System accounts |

## 7. Windows `net` Commands

| Command | Purpose |
|---|---|
| `net accounts /domain` | Domain password and lockout policies |
| `net user /domain` | List domain users |
| `net user <username> /domain` | Enumerate a domain user |
| `net group /domain` | List domain groups |
| `net group "Domain Admins" /domain` | Identify Domain Admin group members |
| `net group "Domain Computers" /domain` | List domain computer accounts |
| `net group "Domain Controllers" /domain` | List Domain Controller accounts |
| `net localgroup administrators` | Display local Administrators group members |
| `net share` | List local shares |
| `net view /domain` | List visible domain computers |
| `net view \\<computer> /ALL` | List visible shares on a computer |
| `net use X: \\<computer>\<share>` | Map a network share |

**OPSEC note:** These commands may be monitored by EDR and other security tools.

## 8. DSQuery — Active Directory Enumeration

`dsquery` searches for Active Directory objects using LDAP-based queries.

### Find Users
```cmd
dsquery user
```

### Find Computers
```cmd
dsquery computer
```

### Search an OU or Container
```cmd
dsquery * "CN=Users,DC=INLANEFREIGHT,DC=LOCAL"
```

### Find Domain Controllers
```cmd
dsquery * -filter "(userAccountControl:1.2.840.113556.1.4.803:=8192)" -limit 5 -attr sAMAccountName
```

### Find Users with PASSWD_NOTREQD
```cmd
dsquery * -filter "(&(objectCategory=person)(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=32))" -attr distinguishedName userAccountControl
```

**Exam tip:** `userAccountControl` flags can help identify accounts with specific security configurations.

## 9. LDAP Filters — Important OIDs

| OID | Meaning |
|---|---|
| `1.2.840.113556.1.4.803` | Bitwise AND: all specified bits must match |
| `1.2.840.113556.1.4.804` | Bitwise OR: any specified bit can match |
| `1.2.840.113556.1.4.1941` | Recursive evaluation of linked DN relationships, such as nested group membership |

### LDAP Logical Operators

| Operator | Meaning |
|---|---|
| `&` | AND — all conditions must match |
| `\|` | OR — at least one condition must match |
| `!` | NOT — negate a condition |

Example:
```ldap
(&(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=64))
```

Matches user objects with the specified UAC bit set.

## CPTS Quick Revision

- **Host info:** `systeminfo`, `hostname`, `whoami`
- **Network discovery:** `ipconfig /all`, `arp -a`, `route print`
- **Firewall:** `netsh advfirewall show allprofiles`
- **Defender:** `sc query windefend`, `Get-MpComputerStatus`
- **Logged-in sessions:** `qwinsta`
- **Domain users/groups:** `net user /domain`, `net group /domain`
- **AD object searches:** `dsquery user`, `dsquery computer`
- **PowerShell logging:** Event ID 4104 relates to script block logging.
- **LDAP filters:** Know the three OIDs and the `&`, `|`, `!` operators.
- **LOTL:** Native tools do not mean invisible tools; activity may still be logged and detected.
