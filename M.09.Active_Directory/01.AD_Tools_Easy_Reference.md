# 🛠️ Active Directory Tools Reference

Simple explanations of what each tool does and where it is commonly used. Use security-testing tools only in systems or labs where you have permission.

| Tool | Easy Explanation | Where to Use It |
|---|---|---|
| PowerView / SharpView | Finds information about AD users, groups, computers, and permissions. Helps you understand who has access to what. | Windows PowerShell / Windows |
| BloodHound | Displays a visual map of relationships and permissions in AD, helping you understand possible paths to higher privileges. | BloodHound application on Windows or Linux; collected data is imported into it |
| SharpHound | Collects AD information and saves it so BloodHound can analyze and display it. | Windows |
| BloodHound.py | Collects data for BloodHound using Python. The computer running it does not have to be joined to the domain. | Kali Linux / Linux |
| Kerbrute | Checks whether domain usernames exist and can test password guesses against accounts. | Kali Linux / Linux; a Windows build may also be available |
| Impacket toolkit | A collection of Python tools for communicating with Windows network services and assessing AD security. | Kali Linux / Linux |
| Responder | Listens for certain local-network name requests and can impersonate a responder, potentially capturing authentication challenge-response data. | Kali Linux / Linux |
| Inveigh.ps1 | A PowerShell tool that can monitor or spoof certain Windows network name-resolution requests, similar to Responder. | Windows PowerShell |
| C# Inveigh (InveighZero) | A C# version of Inveigh with a console for viewing and managing captured network data. | Windows |
| rpcinfo | Checks which RPC services a remote computer advertises. | Linux / Unix |
| rpcclient | Connects to Windows RPC services to query information such as users, groups, and server details when access is permitted. | Kali Linux / Linux |
| CrackMapExec (CME) | An older tool for checking SMB access, enumerating Windows computers, and assessing AD security. Its successor is NetExec (`nxc`). | Kali Linux / Linux |
| Rubeus | Inspects and tests Kerberos authentication and ticket-related behavior in Windows environments. | Windows |
| GetUserSPNs.py | Finds accounts with Service Principal Names (SPNs) and can request service-ticket data for authorized Kerberoasting assessments. | Kali Linux / Impacket |
| Hashcat | Tries possible passwords against supported password hashes to test or recover passwords. | Kali Linux / Linux / Windows |
| enum4linux | Collects information from Windows or Samba systems, such as users, groups, shares, and domain details. | Kali Linux / Linux |
| enum4linux-ng | A newer rework of enum4linux that collects Windows/Samba information with updated options and output. | Kali Linux / Linux |
| ldapsearch | Searches directory information—such as users, groups, and attributes—using LDAP queries. | Kali Linux / Linux; available on other systems too |
| windapsearch | Automates LDAP searches to find AD users, groups, computers, and other directory information. | Kali Linux / Linux |
| DomainPasswordSpray.ps1 | Tests one password against multiple domain accounts to assess password security. Incorrect use can lock accounts. | Windows PowerShell |
| LAPSToolkit | Helps audit LAPS configuration and permissions, including potential weaknesses in how local administrator passwords are managed. | Windows PowerShell |
| smbmap | Lists SMB shares and helps check which shares an account can read or write to. | Kali Linux / Linux |
| psexec.py | Runs commands remotely on a Windows computer through SMB when the account has the required administrative access. | Kali Linux / Impacket |
| wmiexec.py | Runs commands remotely through Windows Management Instrumentation (WMI) when authorized access is available. | Kali Linux / Impacket |
| Snaffler | Searches accessible network shares and computers for potentially sensitive files, including files that may contain credentials. | Windows, usually in an AD environment |
| smbserver.py | Creates an SMB share on your machine so another computer can access or transfer files over the network. | Kali Linux / Impacket |
| setspn.exe | Views, adds, or modifies Service Principal Names associated with Windows service accounts. | Windows Command Prompt or PowerShell with AD tools |
| Mimikatz | A powerful security-testing tool that can inspect credential material and Kerberos tickets on Windows. Some functions can expose sensitive secrets. | Windows; authorized labs only |
| secretsdump.py | Extracts Windows account hashes and other security secrets when sufficient access is available. | Kali Linux / Impacket |
| evil-winrm | Opens a command-line session on a Windows computer over WinRM when valid access is available. | Kali Linux / Linux |
| mssqlclient.py | Connects to Microsoft SQL Server so you can interact with databases using the required credentials and permissions. | Kali Linux / Impacket |
| noPac.py | Tests specific older AD vulnerabilities (CVE-2021-42278 and CVE-2021-42287) in an authorized lab. | Kali Linux / Impacket |
| rpcdump.py | Queries a Windows host's RPC endpoint mapper to list registered RPC services and endpoints. | Kali Linux / Impacket |
| CVE-2021-1675.py | A proof-of-concept associated with the PrintNightmare Windows Print Spooler vulnerability. | Kali Linux / Python; authorized testing only |
| ntlmrelayx.py | Tests whether NTLM authentication can be relayed to another service in a vulnerable environment. | Kali Linux / Impacket; authorized lab only |
| PetitPotam.py | Tests a Windows authentication-coercion weakness that can cause a computer to attempt network authentication. | Kali Linux / compatible tools; authorized lab only |
| gettgtpkinit.py | Works with certificate-based Kerberos authentication to request a Ticket Granting Ticket (TGT) under supported conditions. | Kali Linux / compatible PKINIT tools |
| getnthash.py | Uses an existing Kerberos TGT and a user-to-user Kerberos technique to attempt to obtain the current user's NT hash under supported conditions. | Kali Linux / compatible Kerberos tools |
| adidnsdump | Queries DNS records stored in Active Directory-integrated DNS to discover domain-related hostnames and records. | Kali Linux / Linux |
| gpp-decrypt | Attempts to decrypt passwords stored in the legacy Group Policy Preferences format. | Kali Linux / Linux |
| GetNPUsers.py | Finds accounts that do not require Kerberos pre-authentication and can request AS-REP data for authorized AS-REP roasting tests. | Kali Linux / Impacket |
| lookupsid.py | Queries or enumerates Security Identifiers (SIDs) to help identify domain users, groups, and other accounts where permitted. | Kali Linux / Impacket |
| ticketer.py | Creates or customizes Kerberos tickets for security testing, including testing defenses against forged-ticket attacks. | Kali Linux / Impacket; authorized lab only |
| raiseChild.py | Automates testing of certain privilege-escalation paths from a child domain to its parent domain. | Kali Linux / Impacket; authorized lab only |
| Active Directory Explorer (AD Explorer) | A graphical tool for browsing AD objects, viewing or editing properties, saving snapshots, and comparing changes. | Windows |
| PingCastle | Audits AD security and creates reports that highlight risks and configuration weaknesses. | Windows |
| Group3r | Checks Group Policy Objects (GPOs) for potentially unsafe settings and security misconfigurations. | Windows |
| ADRecon | Collects AD information and organizes it into reports, including Excel output, to help review the environment's security. | Windows PowerShell |

## Tools I Have Used in the Module

### Fping

```bash
fping -asgq 172.16.5.0/23
```

**What it does:** Checks which IP addresses in the specified network range respond to ping requests.

**Where to use it:** Kali Linux / Linux terminal. `fping` may need to be installed first.

### Kerbrute

```bash
./kerbrute_linux_amd64 userenum --dc 10.10.10.10 -d corp.local usernames.txt
```

**What it does:** Checks the usernames in `usernames.txt` against the domain `corp.local` using the domain controller at `10.10.10.10`.

**Where to use it:** Kali Linux / Linux terminal, with Kerbrute downloaded and executable. Replace the example domain, domain-controller IP, and file name with values from your authorized lab.

---

**Reminder:** Tool requirements vary by version. Many tools need network connectivity, suitable permissions, and valid credentials. Use tools that test passwords, collect secrets, or exploit vulnerabilities only in systems you own or have explicit permission to assess.
