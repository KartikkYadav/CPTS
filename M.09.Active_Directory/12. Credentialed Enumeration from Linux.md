# Credentialed Enumeration from Linux

## 1. Overview

**Goal:** Enumerate Active Directory using valid domain credentials to identify users, groups, shares, permissions, sessions, and potential attack paths.

## 2. CrackMapExec (CME) / NetExec

**Help:**
```bash
crackmapexec smb -h
```

**Enumerate domain users:**
```bash
sudo crackmapexec smb <DC_IP> -u '<USER>' -p '<PASS>' --users
```

**Enumerate groups:**
```bash
sudo crackmapexec smb <DC_IP> -u '<USER>' -p '<PASS>' --groups
```

**Enumerate logged-on users:**
```bash
sudo crackmapexec smb <TARGET_IP> -u '<USER>' -p '<PASS>' --loggedon-users
```

**Enumerate SMB shares:**
```bash
sudo crackmapexec smb <DC_IP> -u '<USER>' -p '<PASS>' --shares
```

**Search files using `spider_plus`:**
```bash
sudo crackmapexec smb <DC_IP> -u '<USER>' -p '<PASS>' -M spider_plus --share '<SHARE>'
```

**Important flags:**
- `--users` — Domain users.
- `--groups` — Domain groups.
- `--shares` — SMB shares and permissions.
- `--loggedon-users` — Logged-on users.
- `-M` — Execute a module.

**Key points:**
- Check privileged groups such as `Domain Admins`, `Administrators`, and `Backup Operators`.
- `badpwdcount` helps assess account-lockout risk.
- `(Pwn3d!)` can indicate administrative access.
- Check readable shares for sensitive files and credentials.

## 3. SMBMap

**Enumerate shares and permissions:**
```bash
smbmap -u '<USER>' -p '<PASS>' -d '<DOMAIN>' -H <TARGET_IP>
```

**Recursively enumerate directories:**
```bash
smbmap -u '<USER>' -p '<PASS>' -d '<DOMAIN>' -H <TARGET_IP> -R '<SHARE>' --dir-only
```

**Key points:**
- `READ ONLY` — Read access.
- `READ, WRITE` — Read and write access.
- Prioritize departmental, user, and archive shares.
- Inspect scripts, configuration files, and backups.

## 4. rpcclient

**Attempt anonymous SMB NULL session:**
```bash
rpcclient -U "" -N <TARGET_IP>
```

**Useful commands:**
```text
enumdomusers
enumdomgroups
queryuser <RID>
querygroup <RID>
querydominfo
```

**SID vs. RID:**
- **SID:** Identifies a security principal.
- **RID:** Identifies an object within the domain SID namespace.
- `enumdomusers` lists users and their RIDs.
- `queryuser <RID>` retrieves account information.

**Common built-in RIDs:**
| Account | RID |
|---|---:|
| Administrator | 500 |
| Guest | 501 |
| krbtgt | 502 |

## 5. Impacket

### psexec.py
```bash
psexec.py <DOMAIN>/<USER>:'<PASS>'@<TARGET_IP>
```
- Uses remote service execution.
- Typically requires local administrator privileges.
- Can provide a remote shell as `SYSTEM`.

### wmiexec.py
```bash
wmiexec.py <DOMAIN>/<USER>:'<PASS>'@<TARGET_IP>
```
- Executes commands through WMI.
- Usually runs as the authenticated user.
- Provides a semi-interactive shell.
- May generate detectable process and WMI events.

**Remember:** `psexec.py` commonly provides SYSTEM access; `wmiexec.py` generally uses the authenticated user's security context.

## 6. Windapsearch

**Enumerate Domain Admins:**
```bash
python3 windapsearch.py --dc-ip <DC_IP> -u '<USER>@<DOMAIN>' -p '<PASS>' --da
```

**Enumerate privileged users, including nested membership:**
```bash
python3 windapsearch.py --dc-ip <DC_IP> -u '<USER>@<DOMAIN>' -p '<PASS>' -PU
```

**Other options:**
- `-U` — Users.
- `-G` — Groups.
- `-C` — Computers.
- `--da` — Domain Admins.
- `-PU` — Privileged users.

**Key point:** Nested group membership can grant privileges indirectly.

## 7. BloodHound.py

**Collect AD data:**
```bash
sudo bloodhound-python -u '<USER>' -p '<PASS>' -ns <DC_IP> -d '<DOMAIN>' -c All
```

**Important collection methods:**
- `Group` — Group relationships.
- `LocalAdmin` — Local administrator access.
- `Session` — User sessions.
- `Trusts` — Domain trusts.
- `ACL` — Access-control relationships.
- `ObjectProps` — Object properties.
- `All` — Broad collection, excluding `LoggedOn` in the documented version.

**Workflow:**
1. Collect AD data.
2. Upload JSON files or a ZIP archive into BloodHound.
3. Inspect users, groups, computers, and permissions.
4. Run **Find Shortest Paths to Domain Admins**.
5. Validate potential attack paths.

## 8. CPTS Quick Reference

| Task | Tool | Command/Flag |
|---|---|---|
| Enumerate users | CrackMapExec | `--users` |
| Enumerate groups | CrackMapExec | `--groups` |
| Find logged-on users | CrackMapExec | `--loggedon-users` |
| Enumerate shares | CrackMapExec | `--shares` |
| Search share files | CrackMapExec | `-M spider_plus` |
| Check share permissions | SMBMap | Basic SMBMap command |
| List directories | SMBMap | `-R '<SHARE>' --dir-only` |
| Enumerate users and RIDs | rpcclient | `enumdomusers` |
| Query user information | rpcclient | `queryuser <RID>` |
| Find Domain Admins | Windapsearch | `--da` |
| Find nested privileged users | Windapsearch | `-PU` |
| Identify attack paths | BloodHound | Shortest Paths to Domain Admins |
| Remote SYSTEM shell | Impacket | `psexec.py` |
| WMI command execution | Impacket | `wmiexec.py` |

### Exam Workflow

**Credentials → Users → Groups → SMB Shares → Files → Sessions → Privileged Users → BloodHound → Validate Access**
