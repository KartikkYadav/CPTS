# Additional AD Auditing Techniques

## 1. AD Explorer (Active Directory Explorer)

Purpose: Browse Active Directory, inspect object properties, permissions, attributes, and create AD snapshots for offline analysis.

Key Features:

- Browse AD objects and view their attributes.
- Inspect object permissions and schema.
- Perform advanced searches and save queries.
- Create AD database snapshots for offline analysis.
- Compare snapshots to identify changes in:
  - Objects
  - Attributes
  - Security permissions

Usage:

1. Launch AD Explorer.
2. Connect using valid domain user credentials.
3. Browse AD objects.
4. Navigate to `File → Create Snapshot`.
5. Save the snapshot for offline analysis.

Exam Tip: AD Explorer snapshots are useful for before-and-after comparisons and identifying changes in AD objects and permissions.

## 2. PingCastle

Purpose: Assess Active Directory security posture and identify misconfigurations, vulnerabilities, and security weaknesses.

Key Features:

- Generates domain security reports, maps, and graphs.
- Identifies domain risks and anomalies.
- Enumerates users, computers, shares, trusts, and delegation.
- Provides a domain risk score based on CMMI (Capability Maturity Model Integration).
- Helps identify hosts and security weaknesses.

Get Help:

```
PingCastle.exe --help
```

Run PingCastle:

```
PingCastle.exe
```

Interactive Menu:

| Option          | Function                            |
| --------------- | ----------------------------------- |
| 1 - healthcheck | Assess domain security risk         |
| 2 - conso       | Aggregate multiple reports          |
| 3 - carto       | Map interconnected domains          |
| 4 - scanner     | Perform workstation security checks |
| 5 - export      | Export users or computers           |
| 6 - advanced    | Advanced options                    |

Important Scanner Checks:

| Scanner         | Purpose                       |
| --------------- | ----------------------------- |
| aclcheck        | Check ACL-related permissions |
| antivirus       | Check antivirus               |
| computerversion | Check computer versions       |
| foreignusers    | Identify foreign users        |
| laps_bitlocker  | Check LAPS and BitLocker      |
| localadmin      | Identify local administrators |
| nullsession     | Check null sessions           |
| smb             | Check SMB                     |
| spooler         | Check Print Spooler           |
| zerologon       | Check Zerologon vulnerability |

Useful Command-Line Options:

| Switch          | Description               |
| --------------- | ------------------------- |
| `--help`        | Display help              |
| `--server`      | Specify domain controller |
| `--user`        | Specify username          |
| `--password`    | Specify password          |
| `--port`        | Specify LDAP/ADWS port    |
| `--log`         | Generate log file         |
| `--interactive` | Force interactive mode    |

Exam Tip: Start with the default `healthcheck` to get an overview of AD security risks and misconfigurations.

## 3. Group3r

Purpose: Identify security weaknesses and vulnerabilities associated with Active Directory Group Policy Objects (GPOs).

Requirements:

- Must run from a domain-joined host.
- Requires a domain user account.
- Administrator privileges are NOT required.
- Can run using `runas /netonly`.

Basic Usage:

```
group3r.exe -f results.log
```

Output Options:

| Switch | Description               |
| ------ | ------------------------- |
| `-s`   | Display results in stdout |
| `-f`   | Save results to a file    |
| `-h`   | Display help              |

Understanding Output:

Group3r output uses indentation to represent hierarchy:

- No indentation → GPO.
- One indentation → Policy settings.
- Two indentations → Findings within those settings.

Findings include:

- Relevant GPO settings.
- Interesting or potentially vulnerable configurations.
- Explanation of why the setting is flagged.

Exam Tip: Group3r is specifically useful for auditing GPO configurations and finding weaknesses that other enumeration tools may overlook.

## 4. ADRecon

Purpose: Perform comprehensive Active Directory enumeration and generate detailed reports.

Execution:

```
.\ADRecon.ps1
```

Information Collected:

- Domain and Forest information.
- Trusts, Sites, and Subnets.
- Domain Controllers.
- Users and SPNs.
- Groups and Memberships.
- Organizational Units (OUs).
- Group Policy Objects (GPOs).
- DNS Zones and Records.
- Computers and SPNs.
- Password Policies.
- LAPS and BitLocker information.

Example Output:

```
ADRecon-Report/
├── CSV-Files/
├── GPO-Report.html
└── GPO-Report.xml
```

Important Requirements:

- Microsoft Excel must be installed to automatically generate Excel reports.
- Without Excel, CSV files are still generated.
- The `GroupPolicy` PowerShell module is required for Group Policy output.
- Some checks, such as LAPS and BitLocker, require privileged accounts.

Generate Excel Report Later:

```
.\ADRecon.ps1 -GenExcel
```

Provide the existing report folder when prompted.

Exam Tip: ADRecon is useful for collecting large amounts of AD information in one run. It is particularly useful when stealth is not a requirement.

## 5. Quick Revision – AD Auditing Tools

| Tool        | Primary Purpose              | Key Feature                      |
| ----------- | ---------------------------- | -------------------------------- |
| AD Explorer | Browse and inspect AD        | Create and compare snapshots     |
| PingCastle  | Assess AD security posture   | Risk scoring and healthcheck     |
| Group3r     | Audit Group Policies         | Identify vulnerable GPO settings |
| ADRecon     | Comprehensive AD enumeration | HTML and CSV reports             |

### Important Exam Points

- AD Explorer: Snapshot AD and compare changes over time.
- PingCastle: Evaluate domain security and generate risk scores.
- Group3r: Find vulnerabilities in Group Policy configurations; does not require administrator privileges.
- ADRecon: Collect extensive AD information and generate HTML/CSV reports.
- PingCastle CMMI: Used as the basis for its security maturity scoring.
- ADRecon Excel reports: Require Microsoft Excel for automatic generation.

Pentesting Takeaway: These tools provide additional evidence of AD misconfigurations and security weaknesses, helping produce stronger assessment reports and actionable remediation recommendations.
