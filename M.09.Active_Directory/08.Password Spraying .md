# Password Spraying – Making a Target User List

## 1. User Enumeration Methods

Before performing password spraying, we need a list of valid Active Directory (AD) users.

Common enumeration methods:

- **SMB NULL Session:** Enumerate users through anonymous SMB/RPC access.
- **LDAP Anonymous Bind:** Query AD without credentials if anonymous access is permitted.
- **Kerbrute:** Identify valid usernames using a wordlist.
- **Credentialed Enumeration:** Use valid domain credentials to retrieve user information.
- **OSINT:** Generate potential usernames using company websites, LinkedIn, or email addresses.

### Password Policy

Before spraying, understand the domain's password policy:

- Minimum password length and complexity requirements.
- Account lockout threshold.
- Failed-password counter reset interval.

Always maintain a log of targeted accounts, Domain Controllers, timestamps, and passwords attempted.

## 2. SMB NULL Session Enumeration

An SMB NULL session allows anonymous access to certain SMB/RPC functions when the target permits it.

### Using enum4linux

```bash
enum4linux -U <DC_IP>
```

Extract usernames:

```bash
enum4linux -U <DC_IP> | grep "user:" | cut -f2 -d"[" | cut -f1 -d"]"
```

### Using rpcclient

Connect anonymously:

```bash
rpcclient -U "" -N <DC_IP>
```

Enumerate domain users:

```text
enumdomusers
```

### Using CrackMapExec

```bash
crackmapexec smb <DC_IP> --users
```

Useful output fields:

- `badpwdcount` — Reported number of failed password attempts.
- `baddpwdtime` — Time of the last bad password attempt.

**Note:** Failed-password counters may differ between Domain Controllers. The PDC Emulator can be useful when investigating account lockout information.

## 3. LDAP Anonymous Enumeration

LDAP anonymous binding may allow users to query Active Directory without valid credentials.

### Using ldapsearch

```bash
ldapsearch -h <DC_IP> -x -b "DC=DOMAIN,DC=LOCAL" -s sub "(&(objectclass=user))"
```

Extract usernames:

```bash
ldapsearch -h <DC_IP> -x -b "DC=DOMAIN,DC=LOCAL" -s sub "(&(objectclass=user))" | grep sAMAccountName: | cut -f2 -d" "
```

### Using windapsearch

```bash
./windapsearch.py --dc-ip <DC_IP> -u "" -U
```

**Important LDAP attributes:**

| Attribute | Description |
|---|---|
| `sAMAccountName` | AD account name |
| `userPrincipalName` | User logon name, commonly `user@domain` |
| `cn` | Common Name |

**Note:** Computer accounts may also appear in results and commonly end with `$`.

## 4. Username Enumeration with Kerbrute

Kerbrute uses Kerberos responses to identify valid domain usernames without requiring valid credentials for the enumeration process.

### Command

```bash
kerbrute userenum -d <DOMAIN> --dc <DC_IP> <WORDLIST>
```

Example:

```bash
kerbrute userenum -d inlanefreight.local --dc 172.16.5.5 /opt/jsmith.txt
```

### How It Works

Kerbrute sends Kerberos requests to the Domain Controller.

- `PRINCIPAL UNKNOWN` → The username is invalid.
- Kerberos pre-authentication required → The username exists.

The source example used a wordlist containing 48,705 candidate usernames and identified more than 50 valid accounts in just over 12 seconds.

### Detection and Lockout Risks

- **Event ID 4768:** Associated with Kerberos TGT requests. A large increase may indicate enumeration activity.
- Username enumeration using this method does not itself require password guessing.
- **Password spraying can trigger account lockouts** because failed authentication attempts may count toward the account's failure threshold.

## 5. Credentialed User Enumeration

If valid domain credentials are available, CrackMapExec can enumerate domain users.

### Command

```bash
crackmapexec smb <DC_IP> -u <USERNAME> -p '<PASSWORD>' --users
```

This can provide:

- Domain usernames.
- Reported failed-password counts.
- Last bad password attempt timestamps.

The source also notes that a Windows host with `SYSTEM` access may be able to query AD using the computer account's domain identity.

## 6. CPTS Exam Quick Reference

| Tool / Concept | Important Point |
|---|---|
| `enum4linux -U` | Enumerates SMB users |
| `rpcclient` | Use `enumdomusers` to enumerate domain users |
| CrackMapExec `--users` | Retrieves user information and may show failed-password counters |
| `ldapsearch` | Queries LDAP using a search base and filter |
| `windapsearch -U` | Enumerates AD users through LDAP |
| `Kerbrute userenum` | Identifies valid usernames through Kerberos |
| Event ID 4768 | Kerberos TGT request |
| Event ID 4625 | Failed logon event |
| `sAMAccountName` | AD account name |
| `userPrincipalName` | User logon name, commonly in `user@domain` format |

### Key Takeaways

1. Try SMB or LDAP enumeration when anonymous access is permitted.
2. Use Kerbrute when you have a candidate username wordlist.
3. Use credentialed enumeration when valid domain credentials are available.
4. Check the password policy before password spraying.
5. Record authentication attempts and monitor account lockout risks.
