# Network Information Enumeration (CPTS Notes)

## Why Enumerate Network Information?

Network enumeration is an important step during Windows Privilege Escalation. Besides helping us understand the current host, it may also reveal additional systems that can be targeted later.

Sometimes a machine is **dual-homed**, meaning it is connected to **two or more different networks**. Compromising such a system may allow us to move laterally into another network segment that was previously unreachable. :contentReference[oaicite:0]{index=0}

---

# Objectives

During network enumeration, gather information about:

- Network interfaces
- IP addresses
- DNS configuration
- Default gateways
- Routing table
- Domain Controllers (AD environments)
- ARP cache
- Other hosts recently contacted

This information is useful for both privilege escalation and lateral movement. :contentReference[oaicite:1]{index=1}

---

# Check Network Configuration

### Command

```cmd
ipconfig /all
```

### Information Collected

- Host Name
- Network Adapters
- IPv4 / IPv6 Addresses
- MAC Address
- Default Gateway
- DNS Servers
- DHCP Status
- DNS Suffix
- NetBIOS Status

### Why It Matters

- Identify if the host is **dual-homed**
- Discover internal network ranges
- Identify DNS servers
- Find Active Directory domains
- Understand the network topology

---

# View ARP Cache

### Command

```cmd
arp -a
```

### Purpose

Displays recently communicated hosts by showing:

- IP Address
- MAC Address
- Entry Type (Dynamic/Static)

### Why It Matters

The ARP cache can reveal:

- Domain Controllers
- File Servers
- Administrator Workstations
- Recently contacted systems

Useful for planning **lateral movement**.

---

# View Routing Table

### Command

```cmd
route print
```

### Information Collected

- Active Routes
- Network Destinations
- Gateways
- Metrics
- Network Interfaces
- Persistent Routes

### Why It Matters

Routing tables help identify:

- Multiple connected networks
- Default gateways
- Additional subnets
- Hidden internal networks

This is especially useful on **dual-homed systems**.

# Enumerating Security Protections

Before running privilege escalation tools, identify security controls that may detect or block them.

Common protections include:

- Windows Defender
- Antivirus (AV)
- Endpoint Detection & Response (EDR)
- Application Whitelisting (AppLocker)

Knowing these protections helps decide whether to use automated tools or manual techniques. :contentReference[oaicite:2]{index=2}

---

# Check Windows Defender Status

### Command

```powershell
Get-MpComputerStatus
```

### Information Collected

- Antivirus Enabled
- Real-Time Protection
- Signature Version
- Scan Status
- Defender Engine Version
- Behavior Monitoring
- On-Access Protection

### Why It Matters

This tells us whether Windows Defender is active and if our tools may be detected or blocked.

---

# Enumerate AppLocker Rules

### Command

```powershell
Get-AppLockerPolicy -Effective | Select -ExpandProperty RuleCollections
```

### Purpose

Displays the **effective AppLocker policy** currently enforced on the system.

### Useful Information

- Allowed executables
- Blocked applications
- Allowed scripts
- Allowed installation paths
- User groups affected

### Why It Matters

AppLocker may prevent execution of:

- cmd.exe
- PowerShell
- Custom executables
- Enumeration tools

Understanding these rules helps choose alternative execution methods.

---

# Test if a Program is Allowed

### Command

```powershell
Get-AppLockerPolicy -Local | Test-AppLockerPolicy -Path C:\Windows\System32\cmd.exe -User Everyone
```

### Example Output

```text
Denied
```

### Purpose

Checks whether a specific executable can run under the current AppLocker policy.

---

# Why Enumerate Security Protections?

Modern organizations often deploy:

- Microsoft Defender
- Cylance
- Carbon Black
- CrowdStrike
- Microsoft Defender for Endpoint
- Other EDR products

These products can detect or block:

- WinPEAS
- PowerUp
- Mimikatz
- Seatbelt
- Common Windows commands (e.g., `net.exe`, `tasklist`)

Knowing what protections exist helps determine whether to:

- Use built-in Windows commands
- Modify tools
- Create custom payloads
- Use manual enumeration

---

# CPTS Key Takeaways

- Always enumerate the network before privilege escalation.
- Use `ipconfig /all` to identify interfaces, IPs, gateways, and DNS.
- Use `arp -a` to discover recently contacted hosts.
- Use `route print` to identify additional networks and routing paths.
- Check Windows Defender status before running tools.
- Enumerate AppLocker policies to understand execution restrictions.
- Understanding the environment helps choose the safest and most effective privilege escalation techniques.
