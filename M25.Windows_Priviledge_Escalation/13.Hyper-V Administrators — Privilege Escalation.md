# **Hyper-V Administrators — Privilege Escalation**

## **Overview**

- Members of the **Hyper-V Administrators** group have full access to Hyper-V features.
- If Domain Controllers are virtualized, Hyper-V administrators should be considered equivalent to **Domain Admins**.
- They can potentially clone a Domain Controller VM and access its virtual disk to extract `NTDS.dit` and obtain domain password hashes.

> **Key concept:** Administrative access to a virtualized Domain Controller can provide access to the domain's credential database.

## **Attack Vector 1: Domain Credential Extraction**

If Domain Controllers are hosted on Hyper-V:

1. Clone the live Domain Controller VM.
2. Mount its virtual disk offline.
3. Access the `NTDS.dit` file.
4. Extract NTLM hashes for domain users.

**Impact:** Potential compromise of the entire Active Directory domain.

## **Attack Vector 2: SYSTEM Privilege Escalation via Hard Links**

### **Vulnerability Concept**

- When deleting a VM, `vmms.exe` attempts to restore permissions on its `.vhdx` file.
- The process runs as `NT AUTHORITY\SYSTEM` without impersonating the user.
- By abusing **NT hard links**, a protected SYSTEM file may be targeted for permission manipulation.

### **Attack Chain**

1. Delete a VM.
2. Exploit the hard-link behavior involving its `.vhdx` file.
3. Create a hard link targeting a protected SYSTEM file.
4. Obtain permissions over the target file.
5. Replace a SYSTEM-level service executable.
6. Start the service to execute code as SYSTEM.

### **Relevant CVEs**

- `CVE-2018-0952`
- `CVE-2019-0841`

These vulnerabilities may allow escalation through the hard-link technique.

## **Example Target: Mozilla Maintenance Service**

Executable:

```
C:\Program Files (x86)\Mozilla Maintenance Service\maintenanceservice.exe
```

The Mozilla Maintenance Service runs as SYSTEM and may be startable by unprivileged users.

### **Taking Ownership**

```
takeown /F "C:\Program Files (x86)\Mozilla Maintenance Service\maintenanceservice.exe"
```

### **Service Name**

```
MozillaMaintenance
```

If permissions on the executable are successfully modified, replacing the executable and starting the service could result in SYSTEM-level code execution.

## **Important Mitigation**

- This hard-link attack vector was mitigated by **March 2020 Windows security updates**.
- Always check the target Windows version and patch level.

## **CPTS Exam Quick Recall**

| Finding                             | Potential Impact                               |
| ----------------------------------- | ---------------------------------------------- |
| `Hyper-V Administrators` membership | High privilege over virtual machines           |
| Virtualized Domain Controller       | Potential domain compromise                    |
| Access to `.vhdx` files             | Offline access to VM data                      |
| `NTDS.dit` accessible offline       | Domain credential hash extraction              |
| `vmms.exe` permission restoration   | Potential hard-link abuse                      |
| SYSTEM service executable writable  | SYSTEM privilege escalation                    |
| Unpatched Windows                   | Potential hard-link vulnerability exploitation |

**Remember:** `Hyper-V Admin → VM control → DC disk access → NTDS.dit → Domain compromise`

Or, in the local privilege escalation scenario:

`Hyper-V Admin → Hard-link abuse → SYSTEM service binary → SYSTEM`
