# **Print Operators — Privilege Escalation**

## **Overview**

- Members of **Print Operators** have elevated privileges on Domain Controllers.
- They possess the `SeLoadDriverPrivilege`, which allows loading and unloading device drivers.
- They can manage printers and may log on locally to and shut down a Domain Controller.
- This privilege can potentially be abused to load a vulnerable driver and escalate to **SYSTEM**.

## **1. Enumerate Privileges**

```
whoami /priv
```

Look for:

```
SeLoadDriverPrivilege
```

If the privilege is missing from an unelevated session, **UAC bypass** may be required.

> `SeLoadDriverPrivilege` may initially appear as Disabled. It can potentially be enabled within the process token.

## **2. UAC Bypass**

If running from an unelevated context:

- Use a UAC bypass to obtain an elevated context.
- Alternatively, use GUI access to open an administrative shell with the Print Operators account credentials.
- Recheck privileges using `whoami /priv`.

## **3. Driver Abuse — Capcom.sys**

### **Attack concept**

- `Capcom.sys` is a vulnerable driver.
- It contains functionality that can allow arbitrary shellcode execution as SYSTEM.
- `SeLoadDriverPrivilege` can be abused to load the driver.
- A driver exploit can then result in SYSTEM-level privileges.

### **Attack chain**

```
Print Operators
      ↓
SeLoadDriverPrivilege
      ↓
Load vulnerable Capcom.sys
      ↓
Exploit vulnerable driver
      ↓
SYSTEM shell
```

## **4. Driver Loading Requirements**

A driver can be referenced through registry entries under the user's registry hive.

Relevant registry values:

| Value       | Type        | Purpose            |
| ----------- | ----------- | ------------------ |
| `ImagePath` | `REG_SZ`    | Path to the driver |
| `Type`      | `REG_DWORD` | Driver type        |

### **NT Object Path**

```
\??\C:\Tools\Capcom.sys
```

The `\??\` prefix is an **NT Object Path** used to reference filesystem paths when loading the driver.

## **5. Verify Driver Loading**

Use DriverView to enumerate loaded drivers and confirm whether the vulnerable driver is present.

Look for:

```
Capcom.sys
```

## **6. Exploitation**

The `ExploitCapcom` PoC can exploit the vulnerable driver.

Successful exploitation may result in:

```
Token stealing was successful
The SYSTEM shell was launched
```

Verify the resulting context:

```
whoami
```

Expected:

```
nt authority\system
```

## **7. No GUI Access**

If no GUI is available:

- Modify the exploit's shell-launching function.
- Replace the default `cmd.exe` process with a custom executable.
- The custom executable could be a payload that provides remote access.

The exploit can then execute the specified binary instead of launching a local command prompt.

## **8. Automation**

**EoPLoadDriver** can automate the driver-loading process, including:

- Enabling `SeLoadDriverPrivilege`
- Creating the required registry entries
- Loading the driver through `NTLoadDriver`

## **9. Cleanup**

Remove the registry key created for the driver:

```
reg delete HKCU\System\CurrentControlSet\Capcom
```

## **Important Mitigation**

> Since Windows 10 Version 1803, this specific `SeLoadDriverPrivilege` exploitation technique is no longer exploitable through references to registry keys under `HKEY_CURRENT_USER`.

## **CPTS Exam Quick Recall**

| Finding                      | Significance                               |
| ---------------------------- | ------------------------------------------ |
| `Print Operators` membership | Highly privileged group                    |
| `SeLoadDriverPrivilege`      | Ability to load/unload drivers             |
| Privilege disabled           | May need to enable it in the process token |
| UAC restrictions             | May require UAC bypass                     |
| Vulnerable driver            | Potential SYSTEM escalation                |
| `Capcom.sys`                 | Vulnerable driver used in the example      |
| `ExploitCapcom.exe`          | Exploits the vulnerable driver             |
| `EoPLoadDriver`              | Automates driver loading                   |

**Attack chain:** `Print Operators → SeLoadDriverPrivilege → Load vulnerable driver → Exploit driver → SYSTEM`
