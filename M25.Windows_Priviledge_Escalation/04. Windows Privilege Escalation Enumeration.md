# CPTS Notes – Windows Privilege Escalation Enumeration

## Overview

After gaining a low-privileged shell on a Windows system, the goal is to enumerate the host and identify possible privilege escalation paths.

Possible escalation targets include:

* `NT AUTHORITY\SYSTEM`
* Built-in `Administrator`
* Another user in the local `Administrators` group
* A domain user with local administrator privileges
* A Domain Admin account

> **Enumeration is the key to privilege escalation.** Check the OS, patches, running services, current privileges, users, groups, and installed software. 

---

# 1. Initial Enumeration

## Important Information to Collect

| Information         | Why It Matters                                         |
| ------------------- | ------------------------------------------------------ |
| OS Name             | Identifies Windows version and available features      |
| OS Version          | Helps identify potential vulnerabilities               |
| Patches/Hotfixes    | Missing patches may indicate known exploits            |
| Running Processes   | Identifies interesting applications and services       |
| Running Services    | Misconfigured privileged services may allow escalation |
| Current User        | Determines the current security context                |
| User Privileges     | Identifies exploitable privileges                      |
| Groups              | May reveal administrative or special access            |
| Logged-in Users     | Identifies potential targets                           |
| Installed Software  | May reveal vulnerable applications                     |
| Network Connections | Identifies locally accessible services                 |

---

# 2. System Information

## List Running Processes and Services

```cmd
tasklist /svc
```

Displays:

* Running processes
* Process IDs
* Associated services

Look for:

* Non-standard applications
* Privileged services
* Security software
* Applications such as `FileZilla`, databases, web servers, etc.

Example interesting processes:

```text
FileZilla Server.exe
MsMpEng.exe
spoolsv.exe
lsass.exe
```

`MsMpEng.exe` indicates Microsoft Defender is running.

---

## Display Environment Variables

```cmd
set
```

Important variables:

```text
PATH
HOMEDRIVE
HOMEPATH
USERPROFILE
APPDATA
TEMP
COMPUTERNAME
```

### Check `PATH`

Windows searches for executables using:

1. Current Working Directory
2. Directories listed in `PATH`

A writable custom directory in `PATH` may present interesting escalation opportunities.

Example:

```text
Path=C:\Windows\system32;C:\Windows;...
```

---

# 3. Detailed System Information

## Use `systeminfo`

```cmd
systeminfo
```

Important information:

* Hostname
* OS name
* OS version
* Build number
* System architecture
* Boot time
* Installed hotfixes
* Network adapters
* Domain/Workgroup
* Virtual machine information

Example:

```text
OS Name: Microsoft Windows Server 2016 Standard
OS Version: 10.0.14393
System Type: x64-based PC
```

### Why Check Boot Time?

An extremely old boot time may indicate the system has not been restarted or patched recently.

---

# 4. Check Installed Patches

## Using WMIC

```cmd
wmic qfe
```

Displays installed Windows updates and hotfixes.

Look for:

```text
KB3199986
KB5001078
KB4103723
```

## Using PowerShell

```powershell
Get-HotFix | ft -AutoSize
```

Useful information:

* `HotFixID`
* Description
* Installation date
* Installed by

> Compare the OS version and installed patches when researching known vulnerabilities. System-level exploits can cause instability, so understand the exploit before using it. 

---

# 5. Enumerate Installed Programs

## Using WMIC

```cmd
wmic product get name
```

Displays installed applications.

Look for:

* Old software versions
* File transfer software
* Database software
* Development tools
* Applications that may store credentials
* Software running as privileged services

## Using PowerShell

```powershell
Get-WmiObject -Class Win32_Product | select Name, Version
```

Example output may reveal:

```text
SQL Server
Java
Microsoft Visual C++
VMware Tools
```

---

# 6. Check Network Connections

## Use `netstat`

```cmd
netstat -ano
```

Displays:

* Protocol
* Local address
* Remote address
* Connection state
* PID

Example:

```text
TCP    0.0.0.0:21      LISTENING
TCP    0.0.0.0:80      LISTENING
TCP    0.0.0.0:1433    LISTENING
TCP    0.0.0.0:3389    LISTENING
```

Important ports may include:

| Port   | Common Service |
| ------ | -------------- |
| `21`   | FTP            |
| `80`   | HTTP           |
| `445`  | SMB            |
| `1433` | MSSQL          |
| `3389` | RDP            |

Use the PID to correlate the listening service with a process.

# 7. User Enumeration

## Check Logged-in Users

```cmd
query user
```

Example:

```text
USERNAME        SESSIONNAME     ID   STATE
administrator   rdp-tcp#2       1    Active
```

Check:

* Who is logged in
* Whether the user is active
* Session information

---

## Check Current User

```cmd
echo %USERNAME%
```

Alternative:

```cmd
whoami
```

Always identify your current security context first.

---

# 8. Check User Privileges

```cmd
whoami /priv
```

Example:

```text
SeChangeNotifyPrivilege
SeIncreaseWorkingSetPrivilege
```

Look for unusual or non-default privileges.

Important privileges may provide privilege escalation paths depending on the system configuration.

---

# 9. Check Group Membership

```cmd
whoami /groups
```

This shows:

* Local groups
* Domain groups
* Security identifiers
* Group attributes

Look for memberships such as:

```text
Administrators
Remote Desktop Users
Backup Operators
Remote Management Users
```

Group membership may provide additional access or escalation opportunities.

---

# 10. Enumerate Local Users

```cmd
net user
```

Example:

```text
Administrator
Guest
helpdesk
htb-student
jordan
sarah
secsvc
```

Check for:

* Administrator-like accounts
* Service accounts
* Helpdesk accounts
* Accounts with similar names

Example:

```text
bob
bob_adm
```

This may indicate possible credential reuse or an administrative account.

---

# 11. Enumerate Local Groups

```cmd
net localgroup
```

Important groups include:

```text
Administrators
Backup Operators
Hyper-V Administrators
Power Users
Remote Desktop Users
Remote Management Users
```

Non-standard groups can reveal useful information about the system and its configuration.

---

# 12. Check Members of a Specific Group

## Check Local Administrators

```cmd
net localgroup administrators
```

Example:

```text
Administrator
helpdesk
sarah
secsvc
```

Any unexpected user in the `Administrators` group is important.

---

# 13. Check Password Policy

```cmd
net accounts
```

Important values:

* Minimum password length
* Maximum password age
* Password history
* Lockout threshold
* Lockout duration

Example:

```text
Minimum password length: 0
Lockout threshold: Never
```

A weak password policy may affect further credential testing.

```cmd
whoami /groups

```

## Key Takeaway

```text
Initial Access
      ↓
Identify Current User
      ↓
Check Privileges
      ↓
Enumerate Groups
      ↓
Check OS & Patches
      ↓
Enumerate Processes & Services
      ↓
Check Installed Software
      ↓
Check Network Services
      ↓
Enumerate Users & Logged-in Sessions
      ↓
Identify Privilege Escalation Path
```

> **Remember:** Manual enumeration is an essential CPTS skill. You should understand what each command reveals instead of relying entirely on automated enumeration tools.
