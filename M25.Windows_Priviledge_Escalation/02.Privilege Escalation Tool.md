# Useful Windows Privilege Escalation Tools (CPTS Notes)

During Windows Privilege Escalation, enumeration is one of the most important phases. Various tools help identify common and advanced privilege escalation vectors, but you should always understand what each tool is doing instead of relying on automated results.

| Tool | Purpose |
|------|---------|
| **Seatbelt** | C# tool that performs comprehensive local system enumeration and privilege escalation checks. |
| **WinPEAS** | One of the most popular Windows enumeration tools. Searches for common privilege escalation paths and misconfigurations. |
| **PowerUp** | PowerShell script that identifies and can exploit common Windows privilege escalation misconfigurations. |
| **SharpUp** | C# version of PowerUp with similar functionality. |
| **JAWS** | PowerShell 2.0 enumeration script for identifying privilege escalation opportunities. |
| **SessionGopher** | Extracts saved sessions and credentials from PuTTY, WinSCP, FileZilla, RDP, SuperPuTTY, and other remote access tools. |
| **Watson** | Identifies missing Windows security patches (KBs) and suggests privilege escalation exploits. |
| **LaZagne** | Recovers passwords stored in browsers, databases, email clients, Wi-Fi profiles, Git, memory, and Windows credential storage. |
| **WES-NG (Windows Exploit Suggester)** | Uses `systeminfo` output to identify missing patches and known privilege escalation vulnerabilities. |
| **Sysinternals Suite** | Microsoft's administration toolkit. Common tools include **AccessChk**, **PipeList**, and **PsService** for enumeration. |

---

# Best Practices

- Always compile tools from **source code** when working in client environments.
- If upload permissions are limited, use:

```text
C:\Windows\Temp
```

because the **BUILTIN\Users** group usually has write permissions.

---

# Why Learn Manual Enumeration?

Enumeration tools are extremely useful because they:

- Save time
- Automate hundreds of security checks
- Highlight common privilege escalation vectors

However, they also have limitations:

- Can generate **false positives**
- May miss vulnerabilities (**false negatives**)
- Produce a huge amount of output (especially WinPEAS)
- May not work in restricted environments

For CPTS and real-world engagements, you should always know how to perform the same checks manually using **CMD**, **PowerShell**, and built-in Windows utilities.

---

# Detection & Evasion

Most privilege escalation tools are well known and are detected by:

- Windows Defender
- Antivirus (AV)
- Endpoint Detection & Response (EDR)

Examples:

- Cylance
- Carbon Black
- Microsoft Defender

For example, **LaZagne** is detected by most antivirus products because it extracts stored credentials.

---

# CPTS Key Takeaways

- Enumeration tools speed up privilege escalation but should not replace manual techniques.
- Understand the output instead of blindly trusting it.
- Be prepared to work in environments where tools cannot be uploaded.
- Learn both **manual enumeration** and **manual exploitation**.
- Always verify tool findings before attempting exploitation.
