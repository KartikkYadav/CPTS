# **Event Log Readers**

## **1. Windows Process Creation Auditing (Event ID 4688)**

- Windows records process creation events in the **Security Event Log** when process creation auditing is enabled.
- **Event ID 4688** – A new process has been created.
- Command-line auditing can capture the commands and arguments executed by users.
- Logs can be forwarded to SIEM tools (e.g., Elasticsearch) for threat detection.

**Common attacker commands monitored:**

| Activity                          | Commands                                     |
| --------------------------------- | -------------------------------------------- |
| Initial access / Enumeration      | `tasklist`, `ver`, `ipconfig`, `systeminfo`  |
| Reconnaissance                    | `dir`, `net view`, `ping`, `net use`, `type` |
| Lateral Movement / Malware Spread | `at`, `reg`, `wmic`, `wusa`                  |

**Important:**

- Unusual commands executed from sensitive workstations may trigger security alerts.
- AppLocker can restrict execution of specific Windows commands.
- Command-line auditing may expose passwords passed as command-line arguments.

## **2. Event Log Readers Group**

- Members of the **Event Log Readers** group can read local Windows event logs.
- Administrators also have access.
- Users can be added to this group to provide log-reading access without granting full administrative privileges.

### **Enumerate Group Membership**

```
net localgroup "Event Log Readers"
```

## **3. Searching Security Logs Using&#x20;**`wevtutil`

`wevtutil` is a Windows command-line utility used to query and manage event logs.

### **Search for Commands Containing&#x20;**`/user`

```
wevtutil qe Security /rd:true /f:text | Select-String "/user"
```

**Useful parameters:**

| Parameter       | Description                                |
| --------------- | ------------------------------------------ |
| `qe`            | Query events                               |
| `Security`      | Target event log                           |
| `/rd:true`      | Read events in reverse chronological order |
| `/f:text`       | Display output in text format              |
| `/r:<computer>` | Query a remote computer                    |
| `/u:<user>`     | Specify username                           |
| `/p:<password>` | Specify password                           |

### **Query Remote Security Logs Using Credentials**

```
wevtutil qe Security /rd:true /f:text /r:share01 /u:julie.clay /p:Welcome1 | findstr "/user"
```

**Exam Note:** `wevtutil` supports alternate credentials for querying remote event logs.

## **4. Searching Security Logs Using Get-WinEvent**

`Get-WinEvent` is a PowerShell cmdlet used to query Windows event logs.

### **Find Event ID 4688 Containing&#x20;**`/user`

```
Get-WinEvent -LogName security |
where { $_.ID -eq 4688 -and $_.Properties[8].Value -like '*/user*'} |
Select-Object @{name='CommandLine';expression={ $_.Properties[8].Value }}
```

**Important:**

- Event ID `4688` identifies process creation.
- `Properties[8].Value` contains the process command-line value in this example.
- `-like '*/user*'` filters command lines containing `/user`.
- `-Credential` can be used to execute the query with alternate credentials.

Privilege Requirement

- Querying the Security log using `Get-WinEvent` requires administrator privileges by default.
- Membership in **Event Log Readers alone is not sufficient**.
- Access can also be granted by adjusting permissions on:

```
HKLM\System\CurrentControlSet\Services\Eventlog\Security
```

## **5. PowerShell Operational Logs**

- PowerShell Operational logs may contain sensitive information and credentials.
- Script Block Logging and Module Logging can capture PowerShell activity.
- These logs are accessible to unprivileged users.

## **CPTS Exam Quick Reference**

| Item                          | Important Detail                          |
| ----------------------------- | ----------------------------------------- |
| Event ID                      | `4688` – Process Creation                 |
| Event Log                     | Security                                  |
| Command-line auditing         | Captures executed commands and arguments  |
| Event Log Readers             | Allows reading local event logs           |
| `wevtutil`                    | Command-line event log querying           |
| `Get-WinEvent`                | PowerShell event log querying             |
| `Properties[8].Value`         | Command line in the provided 4688 example |
| Security log via Get-WinEvent | Requires admin or adjusted permissions    |
| PowerShell Operational        | May expose scripts and sensitive data     |
| AppLocker                     | Restricts execution of specific commands  |

**Key Takeaway:** During enumeration, check Event Log Readers membership and use `wevtutil` or `Get-WinEvent` to search event logs. Process creation auditing and PowerShell logging may reveal executed commands and potentially exposed credentials.
