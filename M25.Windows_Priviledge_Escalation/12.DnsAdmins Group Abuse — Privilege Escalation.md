# **DnsAdmins Group Abuse — Privilege Escalation**

## **Overview**

- Members of **DnsAdmins** can manage DNS on Windows servers.
- DNS service runs as `NT AUTHORITY\SYSTEM`.
- DNS supports custom DLL plugins through the `ServerLevelPluginDll` registry value.
- Abusing this functionality can lead to **SYSTEM-level code execution on a Domain Controller**.

> **Key exam concept:** DnsAdmins membership + ability to load a custom DLL + DNS service restart = potential privilege escalation.

## **DLL Hijacking via DnsAdmins**

### **Attack mechanism**

1. DNS management is performed over RPC.
2. `dnscmd.exe` can configure the `ServerLevelPluginDll` registry value.
3. A custom DLL can be specified without path verification.
4. When DNS restarts, it loads the configured DLL.
5. Since DNS runs as SYSTEM, the DLL executes with SYSTEM privileges.

### **Important registry key**

```
HKLM\SYSTEM\CurrentControlSet\Services\DNS\Parameters
```

Value:

```
ServerLevelPluginDll
```

## **Attack Requirements**

- Membership in the `DnsAdmins` group.
- Ability to configure the DNS plugin DLL.
- A malicious DLL accessible to the DNS server.
- Ability to restart the DNS service, or wait for a restart.

**Note:** DnsAdmins membership alone does not necessarily grant permission to restart the DNS service.

## **Enumeration**

### **Check DnsAdmins membership**

```
Get-ADGroupMember -Identity DnsAdmins
```

### **Get user's SID**

```
wmic useraccount where name="USERNAME" get sid
```

### **Check DNS service permissions**

```
sc.exe sdshow DNS
```

Useful service permissions:

| Permission | Meaning       |
| ---------- | ------------- |
| `RP`       | SERVICE_START |
| `WP`       | SERVICE_STOP  |

## **Configure DLL Plugin**

### **Using dnscmd**

```
dnscmd.exe /config /serverlevelplugindll C:\Path\malicious.dll
```

- Requires DnsAdmins privileges.
- Specify the **full DLL path**.
- The command configures the registry value used by DNS.

## **DNS Service Restart**

Check permissions and service status:

```
sc stop dns
sc start dns
sc query dns
```

The DLL is loaded when the DNS service starts.

## **Alternative: Mimilib.dll**

- `mimilib.dll` from Mimikatz can be used as a DNS plugin.
- The `kdns.c` source can be modified to execute a command when DNS queries are processed.
- The plugin can potentially provide command execution as SYSTEM.

## **WPAD Abuse via DnsAdmins**

DnsAdmins can also abuse DNS to facilitate credential theft and traffic interception.

### **Attack concept**

1. Disable the DNS Global Query Block List.
2. Create a `WPAD` DNS record pointing to the attacker's machine.
3. Clients using WPAD may send proxy traffic to the attacker.
4. Tools such as **Responder** or **Inveigh** can be used to capture authentication traffic or facilitate relay attacks.

### **Relevant DNS records**

- `WPAD` — Web Proxy Auto-Discovery
- `ISATAP` — Intra-site Automatic Tunnel Addressing Protocol

These are blocked by default in the Global Query Block List.

## **Cleanup / Remediation**

Remove the malicious plugin registry value:

```
reg delete HKLM\SYSTEM\CurrentControlSet\Services\DNS\Parameters /v ServerLevelPluginDll
```

Restart DNS and verify:

```
sc start dns
sc query dns
```

### **Defensive considerations**

- Restrict membership in `DnsAdmins`.
- Monitor changes to `ServerLevelPluginDll`.
- Audit DNS service restarts.
- Monitor DNS configuration changes and suspicious DLL loading.
- Keep the Global Query Block List enabled.

### **CPTS Exam Quick Recall**

| Finding                           | Potential Impact                                   |
| --------------------------------- | -------------------------------------------------- |
| User is a member of `DnsAdmins`   | Potential DNS privilege abuse                      |
| `ServerLevelPluginDll` configured | Custom DLL may load                                |
| DNS service runs as SYSTEM        | DLL execution may result in SYSTEM                 |
| User has `RPWP` on DNS service    | Can start/stop DNS                                 |
| WPAD block list disabled          | Potential WPAD hijacking / credential interception |

**Attack chain:** `DnsAdmins → Configure DLL → Restart DNS → DLL executes as SYSTEM`
