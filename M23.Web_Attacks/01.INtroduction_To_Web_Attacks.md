#  Introduction to Web Attacks 

## Why web attacks matter
- Web apps are now central to most businesses, so the attack surface is huge and web attacks are the **most common attacks against companies**.
- Compromising an external-facing app can lead to **internal network compromise**, stolen assets, disrupted services, and financial damage.
- Companies with no public web apps are still exposed through **internal web apps** and **external API endpoints**, which are vulnerable to the same attacks.

## The three attacks in this module
For each, the module covers how to **detect, exploit, and prevent** it.

### 1. HTTP Verb Tampering
- **What:** Exploits servers that accept many HTTP verbs/methods by sending requests with unexpected ones.
- **Impact:** Can bypass the app's **authorization mechanism** or its **security controls** against other attacks.
- **Context:** One of several HTTP attacks that abuse web server configuration.

### 2. Insecure Direct Object References (IDOR)
- **What:** The app exposes direct references (sequential IDs, user IDs, file IDs) to objects without proper access control.
- **Cause:** A **weak or missing back-end access control system**.
- **Impact:** Attackers can read other users' files and data by **guessing or calculating IDs**.
- **Note:** One of the most common web vulnerabilities.

### 3. XML External Entity (XXE) Injection
- **What:** Malicious XML is sent to apps that use **outdated XML parsers** to process user input.
- **Impact:**
  - Disclosure of local files (configs with passwords, application **source code**).
  - Source code access enables a **whitebox pentest** to find more vulnerabilities.
  - Can steal the host server's **credentials**, leading to full server compromise and possibly **remote code execution (RCE)**.

## Quick comparison

| Attack | Root cause | Main impact |
|---|---|---|
| HTTP Verb Tampering | Server/app accepts unexpected HTTP methods | Auth/security control bypass |
| IDOR | Missing back-end access control on object references | Unauthorized data access |
| XXE | Outdated/misconfigured XML parsing | File disclosure, credential theft, RCE |

## Key takeaway
All three stem from **trusting client input or misconfigured server behavior**. They are common, easy to overlook, and can escalate from a single flaw to full compromise.
