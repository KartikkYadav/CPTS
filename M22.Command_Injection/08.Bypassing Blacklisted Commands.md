# Bypassing Blacklisted Commands

**Module:** HTB Academy – Command Injections
**Section:** 8 / 12

## Overview

- Covered so far: bypassing single-**character** filters (operators, spaces, slashes, semicolons).
- This section: bypassing **blacklisted commands** (e.g., `whoami`, `cat`) via **obfuscation** — making the command look different while still executing the same way.

---

## Commands Blacklist

- Re-adding `whoami` to an otherwise-bypassed payload → still **`Invalid input`**.
- Indicates a **separate command blacklist filter**, distinct from the character filter.

### Example PHP Command Blacklist

```php
$blacklist = ['whoami', 'cat', ...SNIP...];
foreach ($blacklist as $word) {
    if (strpos('$_POST['ip']', $word) !== false) {
        echo "Invalid input";
    }
}
```

- Checks for **exact substring matches** of blacklisted words.
- Weakness: a **slightly modified** command (same behavior, different literal string) bypasses it.

## Obfuscation Technique: Inserting Ignored Characters

Idea: insert characters into the middle of a command that the shell ignores, so the command string no longer exactly matches the blacklist, but still executes identically.

### Quotes — Linux & Windows

- Works with **single quotes** `'` or **double quotes** `"`.
- Rules: **don't mix quote types**, and the **number of quotes must be even**.

```bash
w'h'o'am'i
# 21y4d

w"h"o"am"i
# 21y4d
```

- Example payload: `127.0.0.1%0aw'h'o'am'i` → successfully bypasses both character and command filters.

### Linux-Only Characters

- **Backslash `\`** and **positional parameter `$@`** are ignored mid-command by bash.
- Unlike quotes, these **don't need to appear in even numbers** — even a single one works.

```bash
who$@ami
w\ho\am\i
```

**Exercise:** Test both in the payload. If blocked, a filtered character may have been used — apply earlier character-bypass techniques to work around it.

### Windows-Only Characters

- **Caret `^`** can be inserted mid-command in CMD without affecting execution.

```cmd
who^ami
# 21y4d
```

## Key Takeaways

| Technique | Platform | Rule |
|---|---|---|
| Single/double quotes | Linux & Windows | Don't mix types; even number required |
| Backslash `\` | Linux only | Any number, including one |
| `$@` | Linux only | Any number, including one |
| Caret `^` | Windows (CMD) only | Inserted mid-command |

- These techniques defeat **exact-string** command blacklists without changing the command's actual behavior.
