# Client-Side Validation Bypass

## Goal

Bypass browser-side file restrictions when uploading a file.

---

## Method 1 — Burp Request Modification

**Use when the browser blocks the file before upload.**

### Steps

1. Select a **valid image** (`.jpg/.png`).
2. Turn **Burp Intercept ON**.
3. Upload the image.
4. Capture the `POST /upload.php` request.
5. Find:

```http
filename="HTB.png"
```

6. Change filename:

```http
filename="shell.php"
```

7. Replace the file content with your payload.
8. Forward the request.
9. Check the response for successful upload.
10. Find the uploaded file URL/path.
11. Access it and test execution if applicable.

### Important

```text
Client-side validation
        ↓
    Burp intercept
        ↓
Modify filename + content
        ↓
Send to server
        ↓
Check if server accepts it
```

**Key idea:** Client-side restrictions can be bypassed because Burp modifies the request before it reaches the server.

# Method 2 — Disable Front-End Validation

**Use when validation is implemented through JavaScript.**

### 1. Inspect the upload input

Look for:

```html
<input type="file"
       onchange="checkFile(this)"
       accept=".jpg,.jpeg,.png">
```

### 2. Identify JavaScript validation

Look for:

```javascript
checkFile(this)
```

Then inspect:

```javascript
function checkFile(File) {
    ...
}
```

Look for extension checks such as:

```javascript
extension !== 'jpg'
extension !== 'jpeg'
extension !== 'png'
```

### 3. Remove/disable the validation

Remove:

```html
onchange="checkFile(this)"
```

Optionally remove:

```html
accept=".jpg,.jpeg,.png"
```

### 4. Upload the file

Select the desired file and upload it normally.

### 5. Find uploaded file

Inspect the page/source and look for something like:

```html
<img src="/profile_images/shell.php">
```

Then access:

```text
/profile_images/shell.php
```

# Fast Exam Checklist

When you see **"Only images are allowed!"**:

```text
1. Is validation happening in browser?
        ↓
2. Capture upload with Burp
        ↓
3. Change filename → shell.php
        ↓
4. Replace file contents
        ↓
5. Forward request
        ↓
6. Check upload response
        ↓
7. Find uploaded file path
        ↓
8. Access uploaded file
```

If Burp modification doesn't work:

```text
Inspect HTML
    ↓
Find onchange / JavaScript validation
    ↓
Find validation function
    ↓
Remove/modify validation
    ↓
Upload file
```

## Remember

- `accept=` → **file picker restriction**
- `onchange=` → **JavaScript validation trigger**
- **Burp** → modify request
- **DevTools** → modify client-side validation
- **Server-side validation** → cannot be bypassed merely by changing browser-side code
