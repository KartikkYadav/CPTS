## 🔄 01. Intercepting HTTP Responses

**[Intercepting HTTP Responses](./01.Intercepting%20HTTP%20Responses.MD)** explains how to intercept and modify server responses before they reach the browser.

### Burp Suite

The notes cover:

- Response interception
- Proxy settings
- Response interception rules
- Response modification rules
- Modifying HTML attributes
- Revealing hidden fields
- Testing whether client-side controls are enforced server-side

### OWASP ZAP

The section also covers:

- Response interception
- Response modification
- HUD features
- Revealing or enabling client-side fields
- HTML comments

### Key Security Concept

Changing the HTML shown to a browser does **not** prove that a restriction has been bypassed. The server should independently validate important input and authorization decisions.

## 🔐 02. Encoding & Decoding

**[Encoding & Decoding](./02.Encoding%20%26%20Decoding.md)** covers common data-encoding formats used in HTTP requests and application data.

### Formats Covered

- URL encoding
- HTML encoding
- Unicode
- Base64
- ASCII hexadecimal

### Practical Workflow

```text
Identify Encoding
      ↓
Decode
      ↓
Understand Structure
      ↓
Modify
      ↓
Re-encode
      ↓
Send Request
      ↓
Analyze Response
```

### Important Point

**Encoding is not encryption.**

Base64 can represent data safely for transport but does not provide confidentiality.

## 🧭 03. Proxying Tools

**[Proxying Tools](./03.Proxying%20Tools.md)** demonstrates how traffic generated by command-line tools and other applications can be routed through Burp Suite or OWASP ZAP.

### Default Local Proxy

```text
http://127.0.0.1:8080
```

### Proxychains

Proxychains can route compatible command-line applications through a configured proxy.

Example:

```bash
proxychains -q curl http://TARGET_IP:PORT
```

The notes cover configuring:

```text
/etc/proxychains.conf
```

### Metasploit Through a Proxy

Metasploit modules can use the module-level `PROXIES` option.

Conceptually:

```text
Metasploit
    ↓
HTTP Proxy
    ↓
Burp / ZAP
    ↓
Target
```

This is useful for inspecting module traffic and debugging web interactions.

## 🕷️ 04. Burp Scanner

**[Burp Scanner](./04.Burp%20Scanner.md)** covers Burp Suite's crawler and vulnerability-scanning capabilities.

### Main Components

**Crawler → Site Map → Passive Scanner → Active Scanner → Findings**

### Target Scope

Scope defines the hosts, URLs, directories, and resources that Burp should process.

The notes emphasize:

- Keep testing within scope
- Exclude dangerous/state-changing URLs when appropriate
- Avoid unnecessary out-of-scope traffic
- Review scope before scanning

### Crawler

Burp Crawler can discover:

- Links
- Forms
- Pages
- Application structure
- Authenticated areas when configured

The notes explicitly distinguish crawling from directory brute-forcing.

### Passive Scanning

Passive scanning analyzes traffic Burp has already observed without actively sending new vulnerability probes.

Examples include detecting:

- Cookie configuration issues
- Potential clickjacking concerns
- Security-related response issues
- Potential DOM-based XSS indicators

### Active Scanning

Active scanning sends additional requests to test for vulnerabilities and should therefore be used carefully within the authorized scope.

## 🧠 Key Learning Points

### Request vs Response Interception

**Request interception** modifies data before it reaches the server.

**Response interception** modifies data before it reaches the browser.

### Client-Side Controls Are Not Security Boundaries

UI changes are useful for testing, but server-side validation determines whether a control is actually enforced.

### Decode Before You Modify

When application data is encoded, understand the original representation, make the change, and restore the expected format.

### Scope Comes First

Proxy and scanning features should be configured around the authorized target scope.

### Scanner Results Need Validation

Automated findings are signals that should be reviewed and, where possible, manually validated.
