### Metasploit Framework: Quick Notes

### **1. Overview**

Metasploit is a Ruby-based, modular penetration testing platform used to write, test, and execute exploit code. It functions as a "Swiss Army knife" for security professionals, providing a centralized environment for vulnerability testing and exploitation.

### **2. Metasploit Versions**

- **Metasploit Framework:** The free, open-source, CLI-based version used for manual exploitation and research.
- **Metasploit Pro:** A commercial version featuring a GUI and advanced automation:
    - **Automation:** Task chains, quick start wizards, and payload generators.
    - **Advanced Features:** Anti-virus/IPS/IDS evasion, social engineering (phishing wizards), and Nexpose/Sonar integration.
    - **Workflow:** Supports team collaboration, web app testing, and detailed reporting.

### **3. MSFconsole Interface**

The most popular and stable interface for the Framework.

- **Centralized Access:** The primary way to access almost all MSF features.
- **Usability:** Supports tab completion, command history (readline), and the ability to execute external OS commands directly.
- **Management:** Handles multiple targets and activities simultaneously using **sessions** and **jobs**.

### **4. Architecture & File Structure**

Base files are typically located at `/usr/share/metasploit-framework`.

- **Data, Lib, Documentation:** The core functional logic and technical manuals.
- **Modules:** The heart of the framework, categorized by function:
    - `auxiliary`: Scanners, crawlers, and fuzzers.
    - `exploits`: Code that leverages vulnerabilities to gain access.
    - `payloads`: Code that runs on the target after a successful exploit (e.g., a shell).
    - `post`: Modules for post-exploitation (gathering data, pivoting).
    - `encoders/evasion/nops`: Tools for bypassing security software and formatting payloads.
- **Plugins:** Add-ons that provide extra automation (e.g., `sqlmap`, `nessus`, `wmap`).
- **Scripts:** Contains Meterpreter-specific functionality and resource scripts.
- **Tools:** Command-line utilities for payload generation and exploit development.
